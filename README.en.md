# ReadFlow: Research Library, Bilingual Reading and Notes

[中文](README.md) · [English](README.en.md) · [Tiếng Việt](README.vi.md)

ReadFlow is a desktop workspace for research reading. It brings together a literature library, PDF reader, reading desk, notes and a canvas for connecting ideas.

Documents, annotations and notes are stored locally. Organizing documents and reading the original PDF do not require a model account. Translation and AI assistance use services you configure.

## Features

- **Organize literature:** import PDFs and Zotero / CSL JSON, then use collections, tags, stars and a reading list.
- **Read bilingually:** open multiple reader tabs, compare originals and translations, resume reading, search, annotate and inspect figures.
- **Translate and recognize text:** use local OCR and selection or full-document translation as needed, with your own service configuration.
- **Develop ideas:** write Markdown notes, revisit annotations and connect excerpts from different papers on a canvas.
- **Review:** create source-linked question, cloze or terminology cards and review them when due.
- **Adjust the workspace:** choose fonts, text sizes, light or dark appearance and service settings.

See the [user guide](docs/readflow/使用说明.md) for configuration, supported workflows and known limitations.

## Download

Download published packages from [ReadFlow Releases](https://github.com/solsongli/ReadFlow/releases/latest). The latest release provides a Linux x86_64 Debian / Ubuntu package.

After installation, open **ReadFlow** and import a PDF. Configure the relevant services in Settings before using translation or AI features.
