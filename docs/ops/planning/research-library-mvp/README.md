# 科研文献管理首版：设计与检查点

> 当前主入口已转为原 RetainPDF 壳内文献管理，见 [原壳预览与验收](native-shell-preview.md)。下文的独立网页路线属于此前原型记录。

记录日期：2026-09-30。仓库：RetainPDF 4.2.5，main，起始 HEAD 857868407aeace94ccf5d8cf0bcf90aecae3b7bf。

本目录为新规划记录，接续[既有工程规划](../README.md)，不覆盖旧台账。用户已选择先开源、降低 Zotero 迁移成本，并于本轮授权持续实现到可本地试用版本；普通可逆代码改动不再逐项等待批准。当前父线程负责检查点与独立验收；未接入用户此前指定但无法访问的其他会话。文档中的目标、候选和验收条目不代表功能已经实现。

## 首版闭环

用户能导入 PDF 或 Zotero 书目，校正标题、作者、日期、DOI，放入合集并加标签；阅读原 PDF、保存带物理页码的摘录和双语笔记；检索可跳回原页的原文证据；导出 Markdown 笔记及书目数据。先让单篇可靠使用，再考虑跨论文比较。

优先特色：
- 原文摘录、用户评论、译文分开保存并联动页码。
- 阅读卡片逐项记录问题、方法、结果、限制和支持该项的原文。
- AI 生成的结论必须有明确原文依据；无依据时显示缺口。
- 跨论文比较为后续候选，不能先把全库检索当成可信综合结论。

首版非目标：完整替代 Zotero、Word/LibreOffice 引用关系迁移、插件数据通用还原、云同步/多人协作、浏览器抓取插件、自动 OCR 所有扫描 PDF、自动联网补全文献、无人确认的付费模型调用。

## 实施方式与当前约束

系统缺少可用 Cargo 工具链，已有 Node 依赖与桌面包 Python 可以运行。首个可用版本采用项目内新增 Web 入口和可替换 Python 本地适配层，使用单独的新 SQLite 与受管理 PDF 文件。原 Rust API、翻译流水线和旧数据目录保持原样；新入口不是将两套数据库默认为同一个权威库。它验证交互、数据契约和迁移语义，随后再将确认的持久化契约纳入 retain-db。

默认启动器必须指向显式隔离目录，绑定回环地址；不探测或自动导入旧库。运行前不读取真实 Zotero SQLite、用户凭据、浏览器资料或私人文献。已有模型配置只能检查健康/可用状态，不回显或改写凭据。离线模型 mock 是接口测试；原文证据检索是本地检索，不能标成真实 AI 验证成功。

## 分阶段任务与完成条件

| 阶段 | 工作 | 可以判定完成的证据 |
| --- | --- | --- |
| 0 | 工作区哈希基线、迁移设计、许可证清单、已有离线检查 | 原有 14 个改动字节不变；新增文档与实际测试结果可审阅 |
| 1 | 标准 CSL JSON 和官方 API v3 JSON 的预览/导入 | 合成样本预览总数可核对；来源 ID 可追踪；再次导入无重复；缺失字段可见 |
| 2 | 新文献、合集/标签、PDF 关联与持久笔记 | 新库可启动；刷新及服务重启后笔记仍在；同内容文件不混淆文献身份 |
| 3 | 原 PDF 阅读、页/块解析及原文证据跳转 | 文本 PDF 真正渲染；摘录关联附件/修订/物理页；扫描页明确需要 OCR |
| 4 | Markdown/书目导出、导入事务和恢复检查 | 文件可下载，Unicode/特殊符号保留；失败不半导入；回滚不删除已有或后改数据 |
| 5 | 真实 AI 受控验证 | 模型调用范围、外传内容和费用获得授权后，实测答案、原文引用、无依据拒答和费用限制 |
| 6 | retain-db 融合、完整附件迁移、更多批注几何类型及发布 | 对应合成与真实授权样本通过；恢复验证和发行许可证清单完成 |

阶段 1—4 可连续进行，不等待重复确认。阶段 5 的费用/资料外传与阶段 6 的公开发布未获本次授权。

下一最小可逆切片为纯合成导入预览及其来源键测试，然后增加隔离 SQLite 事务；不从实际旧库开始迁移。不承诺尚未验证的格式或全字段无损。

## 真正待用户决定

1. 日常写作以 Word 还是 LaTeX/Markdown 为主？首版均可保存书目，但 Word 文档中已有动态引用继续由 Zotero 维护。
2. 是否允许未来真实 AI 测试发送合成论文摘录到指定供应商？若允许，需指定模型及单次/每月预算；目前继续离线实现。
3. 首批迁移更偏个人 Zotero 库还是导出的文件？群组库、扫描论文占比和复杂批注可在首版试用后确定优先级。
