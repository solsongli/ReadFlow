# 思考画布（R3 开发版）

思考画布已包含在 0.9.4 中。

在侧栏「画布」区点 +，为课题命名，例如「第二章 · 相关工作」，也可以关联一个文献分组。画布作为标签页打开；菜单可重命名、改变关联或删除。删除画布不会删除文献、批注和笔记。

阅读器右侧的「画布」标签可以选择正在使用的画布。工具栏切换「只看文献 / 文献 + 画布 / 只看画布」；分屏时拖动分隔条调整宽度。

## 从阅读到整理

- 将选中的原文拖到画布，会创建当前颜色的高亮，并生成摘录卡。
- 已有批注也能拖入：拖动批注卡经过右侧「画布」标签，该标签会展开；也可以用卡片 ⋯ 或选中工具条的「加入画布…」。
- 将文献库条目拖到画布标签，标签会打开，再松开到画布中即可生成文献卡。
- 点摘录卡或图片卡的来源，回到对应论文与页码，并闪烁关联批注。
- 已经加入画布的批注旁显示「画布」角标；批注栏也列出所在画布，点击可定位到卡片。
- 删除被引用的批注时，可以一并删除画布卡，也可以保留为静态摘录。保留后仍有原文、来源和截图，但不再跟随批注，显示「原批注已删除」。

## 排列想法

用 + 添加 Markdown 便签、待解决卡、文字标签或分组框。框选截图加入画布后成为图片卡。双击编辑自己的文字，拖动移动，右下角调整尺寸。

- Shift 单击加选，空白处拖动框选。
- 空格加拖动、中键拖动或双指滚动平移。
- Ctrl + 滚轮或触控板捏合缩放，以指针位置为锚；「适应全部」查看全貌。
- 悬停卡片右边缘，拖动连接点到另一张卡，生成连线；选中连线可修改标签和箭头样式。
- 开启「吸附」使用网格。多选后可左对齐、顶对齐、水平居中或等距分布。
- 完全放进分组框的卡片随框一起移动。
- 搜索框定位文字，Enter / Shift Enter 在结果间切换。
- Delete 删除所选；Ctrl D 复制；Ctrl Z / Ctrl Shift Z 撤销或重做。

## 保存与导出

拖动结束或编辑结束后自动保存，底部显示保存状态。网络错误时保留本次修改并提供重试；同一元素的多窗口写入以后写入的版本为准。

「导出提纲」生成 Markdown：分组框为标题，卡片按从上到下、从左到右排列，摘录带来源、页码、引用键，关系写成「A —对比→ B」。本轮不嵌入截图、不提供 PNG 导出。

撤销最多保留本会话 50 组操作；删除来源批注等外部修改会清空受影响画布的撤销记录。重启后画布内容保留，视角回到默认。连线不会自动绕开其他卡片；重叠分组按空间顺序归入首个框。
