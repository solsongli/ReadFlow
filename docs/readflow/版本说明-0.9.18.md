# ReadFlow 0.9.18

本版修复原版式译文中“擦掉多行，却只写入末行”的占位缺陷。

- **图片实际可见区域**：跟踪 PDF 每次图片绘制的裁剪栈，支持混合直接图片和 Form 图片。图片原始尺寸中已裁掉的部分不再挡住摘要或图注；原图片内容不修改。
- **表格与共享文字行**：用相邻图注与真实表格横线确认表格边界，避免旧缓存的图表框跨入图注。共享首尾行按物理行分配所有权；必要时留空狭窄首行剩余部分，从下一完整行开始。窄边障碍造成的连续区域会安全合并，不能越过图形。
- **摘要**：ACT 的摘要前半段其实已有中文缓存，之前被错误图片障碍完整挡住。两段摘要现在正常替换；Abstract— 在新翻译请求中作为独立 head，粗体/斜体切换不应丢掉正文。
- **上下标与圈号**：自动缩放只看行框时，上下标可能触发字形越界保护。省略前会明确在允许的 55% 字号下试排全文。将分离的 1⃝/2⃝ 等转换为等价的 ①/② 排版，缓存和数字含义不变。
- **疑似挤压诊断**：layout-audit 与语料审计记录可写高度小于原块 35% 的高块，以及以省略号结尾的输出；正常绕图多片按合并纵向覆盖判断，避免把其中一个小片当成整块。

已有译文在阅读器翻译菜单选择「仅重新排版」即可应用，不产生模型费用。
本版基于 RetainPDF（MIT），保留原版权与第三方许可，不新增依赖。
