# ReadFlow 0.9.12

本版新增**保持原版式的译文 PDF**。原来的单栏译文保留为「重排版」。

- 每页保留原尺寸、CropBox、旋转、图表位置、公式、页眉页脚和页码，翻译文字写回原块区域。PDF 原生注释、链接保留，已有书签只更新已翻译的标题。
- 使用内置思源宋体字形子集；标题加粗，上下标按结构化数据绘制。字号从原字号开始，最多缩小到 55%，必要时再压缩行距或显示省略。完整内容保留在块译文缓存中。
- 跨栏／跨页按各段可用容量分配，优先在句子或标点处分开，不截断英文单词。图片、独立公式、图表和代码区域不被正文覆盖。
- 「译文」默认原版式，可选择并记住「原版式／重排」。对照模式下原版式与原文保持同页同位置。
- 导出提供「原版式 PDF（推荐）」「重排 PDF」「LaTeX 工程」。全文任务先生成原版式，再生成重排版，进度分别显示。
- 已有块译文可点「生成原版式／仅重新排版」，不需要模型凭据，也不发送模型请求。旧重排文件继续可读。
- 原位阅读的章节标题改为原字号粗体；长图内标签先进一步缩小，放不下才省略，悬停显示全文。

## 使用限制

- 补翻后采用整篇重生成，避免部分页更新与字体资源不一致；不会更改原附件。
- 扫描影像中的文字无法在「不修改图片」前提下单独擦除；此类区域、位图标签、过小或与受保护内容冲突的区域会保留原文并计入诊断。重排版和块卡片仍可查看完整译文。
- 原始拆块边界不准确时，渲染器优先保护图表，可能保留局部原文。跨段分配不等同逐句对齐；过长内容可能省略。
- 保留的是原 PDF 自带的注释。工作台批注仍由文献库单独管理，本轮不把它们绘入导出文件。

## 维护说明

新模块 `paper_blocks_layout` 使用 PyMuPDF 1.26.5，按原生行内归属的字形范围执行仅文字红删，并根据表题与对齐横线额外保护旧缓存漏识别的三线表，预先确认译文能写入再删除原文字。HTML 只由转义文本和允许的 sup／sub 生成，不执行模型提供的标记。

本机 MuPDF 的完整 CFF 字体子集化存在异常，因此复用已内置的 Typst 预制本篇字形子集，再补齐 Unicode OpenType 映射交给 `insert_htmlbox`。Typst 在此仅用于字体准备，不负责原版式排版；未新增依赖。单栏重排仍沿用现有 Typst 模板。

原页透明组封装在背景 Form 中，新增译文处于其外，避免 Poppler 在叠加文字后丢失照片。原 PDF 的图片和非文字矢量保持；Type 3 字体本身画成路径的字形需要与真正的图形分开统计。

输出：`translated-layout.pdf` 与旧路径 `translated.pdf`（重排版）。字体缓存和诊断均位于现有 `paper-blocks/<sha256>/` 下，没有新增数据根目录。

安装：`sudo apt install ./readflow_0.9.12_amd64.deb`。
