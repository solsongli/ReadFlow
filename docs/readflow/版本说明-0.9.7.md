# ReadFlow 0.9.7

本版让块级翻译直接处理扫描页和图内文字。版面模型、OCR 与 CPU 推理组件随应用提供，无需用户另行下载。

- 内置 PP-DocLayout-S，与既有文字层分析融合；保留 X1 的段落、公式、参考文献与阅读顺序规则。
- 内置 PP-OCRv5 mobile：优先文字层，扫描页自动识别，位图标签补充 OCR。版面／识别结果按页缓存。
- 图片卡显示图注和图内文字对照；译文 PDF 可在原图副本上叠加文字，放不下则保留原文。在「设置 → 翻译」可关闭叠加。
- 批量翻译带论文题名和章节上下文；自动协商 JSON 模式，支持截断拆批、选择性补译、429／5xx 退避和取消。
- 显示服务返回的本次 token 用量。只有主动翻译才发送文字，任务凭据不落盘。

## 组件与许可

固定 URL、版本、大小、SHA-256 见 `ops/models/manifest.json`。ORT 1.25.1、NumPy 2.3.5，PP-DocLayout-S 约 4.7 MiB、PP-OCRv5 mobile det／rec／字典约 20.5 MiB。未引入 OpenCV、RapidOCR 或其他项目的推理封装。

S 型暂无 PaddlePaddle 官方 ONNX 包，本版采用 oar-ocr v0.3.0 发布的 PaddlePaddle 权重转换；OCR 来自 RapidAI 官方 v3.9.2 仓库。模型 Apache-2.0、ORT MIT；用户指定的 NumPy 及部分传递依赖是 BSD 许可，按实际许可保留，详见根目录 `LICENSE.third-party.md`。版权与第三方许可保持完整，见根目录许可文件。

## 使用边界与验收

- 内置识别针对印刷文字和常见中英论文；倾斜、竖排、低清扫描及复杂数学仍可能识别不全。轴对齐字框不是通用透视校正。
- 版面模型只补充高置信区域；低置信仍用启发式。图中文字过密、原框过小或识别错误时请核对原图。
- 很长的单块若连续被服务截断，保留原文并计入回退提示，不伪造译文。现有兼容流水线仍保留，本轮未重写其行为。
- token 数来自服务响应；未返回 usage 时不显示，不作为收费凭证。
- 本轮没有调用 DeepSeek 或其他真实服务。维护者可将服务设为 DeepSeek，填写自己的凭据、官方兼容 API URL 和模型名后验收；不能以本地假译文代替真实质量判断。
- 离线假服务：`python3 ops/development/readflow_fake_openai.py --port 48991`；设置自定义服务、`http://127.0.0.1:48991/v1`、非空测试凭据、模型 `readflow-test`。预览外部模型开关需由维护者开启。
- 不良响应测试模型名：`readflow-fenced`、`readflow-length`、`readflow-rate-limit`、`readflow-missing`、`readflow-tampered`、`readflow-no-json`；均只在该本地假服务中解释。

## X2c：数学密集段落与结果语义

本轮只使用已授权的公开 SafeVLA PDF 与 blocks.json，不读取其翻译缓存、配置或密钥，不调用真实翻译服务。用本地假服务重排，已目检译文第 3–5 页。

根因是按 glyph bbox 判断行距：上下标使相邻行 bbox 重叠，旧规则拒绝小于 -0.5pt 的间距；同时单凭数学字体占比大于 45% 会把完整英语句子判成公式。版面模型只给这些既有碎片补标签，并未主动切行。

- 按正文基线和字体族判断连续行，数学字体切换不再打断段落；真正段距、缩进与栏目边界仍保留。
- 展示公式同时检查数学内容、独立区域、居中／编号、前后留白；编号、极限、上下标碎片归入同一矢量裁剪。
- 行内保护片段保留精确源偏移，段落合并时重定位；模型只看到占位符，super/sub 仍由本地结构还原。

| 原文范围 | X2b 块摘要 | X2c 块摘要 |
|---|---|---|
| 第 3 页 | 9 text + 1 formula；CMDP 定义是 6 text + 1 formula | 4 text；CMDP 定义完整为 1 text |
| 第 4 页 | 19 text + 5 formula；CMDP→VLA 定义 6 text + 1 formula，任务定义 3 text | 9 text + 4 formula；两处定义各为 1 text，式 (2) 包含 π 的星号 |
| 全篇 | text 174；违规单行碎片 36；单字符公式 1 | text 131；违规单行碎片 0；单字符公式 0 |

碎片口径：相邻 text 块中，前块无句末标点、后块以小写开头、同页同栏且行距连续；统计其中只有一个源物理行的块。完整短段和公式引导语不计作错误。物理段落合并不等于删文：附录原有 294 行正文的覆盖仍有回归断言。

### 结果与用量

- `result.render_fallback`：排版失败、退回原文的块 id。
- `result.label_fallback`：仅图内部分标签保留原文的图块 id；图表正常渲染，界面明确分开提示。
- `result.translation_fallback`：尚未成功翻译的条目 id，与上两者分开。新结果不再写语义混杂的 `fallback_blocks`；旧结果仅显示历史保留项提示，重新排版后再分类。
- `usage.reasoning_tokens` 读取 `completion_tokens_details.reasoning_tokens`、`output_tokens_details.reasoning_tokens` 或平铺同名字段，并跨批次累计。它是已报告用量的子集，不再次加进 total；界面显示「其中推理约 N」。
- 不按总量偏大推测推理量；服务未提供字段就不显示。未加入未经服务确认的通用关闭思考参数。假服务模型 `readflow-reasoning` 可验证此协议。

验证：tsc、build、Web 331、桌面 100、后端 376（含本地 SafeVLA 与独立慢基准）、启动器／假服务 24、CI 检查 3 项通过；新增离线明暗场景验证独立提示与推理统计。合成数学 PDF、Typst 源码及生成器在 `frontend/web/tests/fixtures/blocks/math-paper*` 与 `generate-math.py`。

对照统计、假译文和第 3–5 页截图：`/tmp/readflow-x2c/statistics.json`、`/tmp/readflow-x2c/final/translated.pdf`、`/tmp/readflow-x2c/screenshots/`。假译文不代表真实翻译质量；行内字符仍依赖原 PDF 的字符映射，本轮不做数学符号重识别。提取器升为 hybrid-7，合并后 id 改变的块需补翻并重新排版。

补充了双栏公式编号归属回归：编号按同栏、同基线、最近公式绑定，防止右栏编号附到左栏公式。
