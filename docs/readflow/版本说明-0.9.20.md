# ReadFlow 0.9.20

本版打磨页边批注与块译文旁排，使卡片更贴近原文位置，也减少连续阅读时的视觉负担。

- 单栏段落横跨页面中线时，按两侧当前占用和锚点距离分配；双栏论文仍保持左栏在左、右栏在右。
- 全部旁排只显示译文正文。标题与操作在悬停或键盘聚焦时浮现，不再占用卡片高度。
- 全部旁排的卡片在对齐位置不变的前提下，向下延伸到同侧下一张卡片之前，尽量完整显示译文；仍放不下时使用渐隐并提供“展开”。
- 单击段落打开的卡片会使用从锚点到可视区底部的空间，确实放不下时才内部滚动。
- 右侧引线连接段落右缘，避免穿过正文；左侧仍连接左缘。
- 页边批注可见时，新建批注直接聚焦页边说明框，不再同时显示页内编辑框。窄窗口收起为图标时仍使用页内编辑框。
- 段首粗体由结构化 runs 呈现；旧缓存缺少粗体标记时，可依据源块的粗体起始字体在本地恢复，不重新翻译。

本版不改翻译缓存与批注存储，不新增模型、依赖或网络访问。
