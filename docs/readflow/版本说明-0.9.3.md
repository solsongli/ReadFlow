# ReadFlow 0.9.3

- **统一工作台**：移除旧首页、旧详情页及原型界面，只保留工作台和阅读器。MIT 许可证、版权及上游来源说明保持不变。
- **全文翻译**：详情、书桌、阅读器工具栏、多选和命令面板均可发起翻译；提交前检查服务配置及本地 OCR，显示阶段进度和易懂的错误说明，支持重试和取消。
- **对照阅读**：翻译完成后提示打开对照；已打开的阅读器自动刷新译文并保留页码，可切换原文、对照和译文模式。
- **重复导入**：相同 PDF 不再创建新条目，返回并选中已有文献；原条目在回收站中时会恢复。批量导入汇总已存在数量，不自动合并历史重复项，不改变 Zotero / CSL 去重。

翻译需自行配置服务。文字版 PDF 优先使用文字层，扫描件需要已安装的本地 OCR 模块。暂不支持只删除译文或选中即译。
本版继续基于 RetainPDF 4.2.5（MIT），沿用现有翻译与 OCR 流水线。

安装：`sudo apt install ./readflow_0.9.3_amd64.deb`。升级保留 `~/.config/ReadFlow` 中的个人数据，建议升级前备份。
