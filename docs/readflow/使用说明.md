# ReadFlow 使用说明

适用于 ReadFlow 0.9.11 Linux 桌面版。

## 安装、启动与卸载

本版安装包适用于 x86_64 的 Debian／Ubuntu 系发行版。进入安装包所在文件夹，在终端运行：

```sh
sudo apt install ./readflow_0.9.11_amd64.deb
```

安装后从应用菜单打开 **ReadFlow**，也可以在终端运行 `readflow`。若安装器提示缺少系统依赖，请按提示补齐；离线安装需预先具备这些依赖。

ReadFlow 与旧版 RetainPDF 使用不同的应用名称、安装目录和数据目录，可以并存。ReadFlow 不会自动搬移旧版的文献或设置；请通过导入功能加入所需资料。

关闭窗口通常会收起到系统托盘；要完全退出，请在托盘菜单选择「退出」。卸载前先完全退出，再运行：

```sh
sudo apt remove readflow
```

卸载软件不会主动删除个人文献和设置。升级或卸载前建议按下文备份。

## 第一次打开与导入

空库会显示欢迎页。你可以直接导入资料，也可以先设置翻译服务；整理文献和阅读原文不需要模型账户。

### PDF

点击欢迎页的「导入 PDF…」，或文献库工具栏的「+ → PDF 文件…」，选择一个或多个 PDF。也可以把 PDF 拖到窗口任意位置，看到「松开以导入 N 个 PDF」后松开。非 PDF 文件不会导入。

导入完成后在文献库选中条目，检查题名、作者等信息；PDF 没有完整元数据时，可在详情面板补充支持编辑的字段。扫描件可以先阅读，再按需执行本地 OCR。

### Zotero / CSL JSON

1. 在 Zotero 中选中文献并导出为 **CSL JSON**；也支持包含条目列表的 Zotero API JSON。
2. 在 ReadFlow 选择「+ → Zotero / CSL JSON…」，打开该文件。
3. 查看导入预览中的文献、分组、标签和笔记数量及警告，再点「确认导入」。

JSON 中没有提供的信息不会凭空补齐；CSL JSON 通常以书目信息为主。JSON 引用的本机附件路径不会自动复制 PDF，请另行导入需要阅读的文件。同一来源重复导入会按来源标识更新；请保持来源文件名稳定。大文件可分批导出（单次最多 5,000 条、16 MiB）。

### Zotero Connector

ReadFlow **默认开启**浏览器保存接收。从应用菜单正常启动即可使用，不需要再通过终端开启。Connector 浏览器扩展仍需自行安装。

1. 打开「设置 → 文献库 → Zotero Connector」。
2. 确认状态显示「正在接收 · 127.0.0.1:23119」。
3. 在浏览器的文献页面点击 Zotero Connector 保存按钮；支持的页面会保存书目信息，并在可用时附带 PDF。返回文献库即可查看。

「接收浏览器 Zotero Connector 的保存」开关会保存在本机。切换后显示「重启 ReadFlow 后生效」；可以点击「立即重启」，也可以稍后从托盘完全退出，再从应用菜单打开。重启前会先清理 ReadFlow 自己的后台服务。状态行表示当前实际运行状态，保存开关不会立即停止或开启当前接收器。

**端口冲突**：Zotero 桌面版或其他软件可能占用 23119。此时设置显示「端口已被占用（Zotero 可能正在运行），未启用」，并在能够识别时显示占用者。ReadFlow 不会抢占或结束对方进程，文献库、阅读和笔记照常可用。若希望由 ReadFlow 接收，先自行正常退出占用端口的软件，再完全退出并重新打开 ReadFlow；也可继续使用 Zotero，通过 CSL JSON 和 PDF 导入 ReadFlow。「刷新状态」只重新读取状态，不会抢占端口或启动接收器。

**高级用法**：启动环境变量优先于已保存的开关。需要指定接收端口时，可在完全退出 ReadFlow 后运行：

```sh
RETAIN_PDF_RESEARCH_CONNECTOR_PORT=23119 readflow
```

将该变量设为空字符串可在这次启动中关闭接收：

```sh
RETAIN_PDF_RESEARCH_CONNECTOR_PORT= readflow
```

也可指定其他未占用端口，但浏览器扩展的接收地址需要与之匹配。环境变量覆盖存在时，设置会明确提示；「立即重启」会继承当前启动环境，保存的开关在之后从应用菜单正常启动时使用。

Connector 的兼容范围有限，不等同于完整 Zotero：网页快照、站点附件解析器及文字处理器引用集成等尚未支持。若某个站点保存失败，使用 CSL JSON 和 PDF 导入即可。ReadFlow 不提供 Zotero 云同步。

## 文献库

侧栏提供全部文献、待读、星标、最近阅读、未分组、**有笔记的文献**和回收站；部分空分类会隐藏。「有笔记的文献」按篇计数，包含有自由笔记或批注的文献。

- **分组**：支持子分组，一篇文献可加入多个分组。拖动选中的文献到分组即可加入；也可按 `G` 选择分组。分组的「⋯」或右键菜单可新建子分组、重命名、删除。删除分组不会删除文献。
- **标签与星标**：点击侧栏标签筛选；在详情中维护标签，用星标标记重点文献。标签较多时点击「更多」。
- **排序与显示**：工具栏可按添加时间、标题、年份、作者、出处升降序排列。「显示」菜单切换双语／紧凑密度，以及列表／按分组布局；按分组时，多组文献会在每个所属分组中各出现一次。
- **搜索**：搜索会筛选当前视图，可匹配中英文题名、作者、DOI、出处、引用键和标签。工具栏显示当前筛选及结果数量，点击清除按钮取消筛选。
- **多选**：`Ctrl` 单击逐个选择，`Shift` 单击连续选择；详情区会显示批量操作。
- **详情**：查看摘要、分组和信息，编辑中文题名、出处、引用键等；可复制参考文献或 BibTeX、导出 Markdown，并查看最近笔记。
- **回收站**：删除操作会把文献移到回收站，之后可以恢复。0.9.4 工作台没有永久清空回收站入口。

双击文献或按 `Enter` 打开阅读器。长题名被截断时，将鼠标停在题名上可查看全文。

重复导入相同 PDF（文件内容相同，即使改过文件名）会选中已有文献并提示，不再新建条目；若它在回收站中，会恢复原条目，保留笔记、分组等信息。批量导入会汇总已存在的篇数。历史重复条目不会自动合并，Zotero / CSL 的去重规则保持不变。

## 阅读、翻译与批注

每篇文献在工作台中打开一个阅读器标签；切换标签不会重置当前阅读位置。阅读器跟随工作台的浅色／深色设置，PDF 页面可独立选择白色、米色或夜间。

### 原文与译文

先在「设置 → 翻译」填写服务地址、模型和 API Key 并保存，顶部显示「已就绪」。保存不会自动发送翻译请求。未配置时，翻译入口会提示「还没有配置翻译服务」，可直接进入设置。

选中文献后点击「翻译全文」，或使用书桌「翻译 PDF」、阅读器顶部「翻译全文」。多选文献可以「翻译所选」，命令面板也提供入口。系统优先读取 PDF 的文字层，扫描或缺字页面使用本地 OCR；模块未安装时会引导到设置，不会自动下载。

提交后，文献行、详情、书桌和阅读器显示文字识别、翻译或排版阶段与进度。同一 PDF 已有进行中的翻译任务时会复用它。完成提示可直接「对照阅读」；已打开的阅读器自动刷新译文，保留上次页码，无须关掉重开。

进行中的任务可从阅读器顶部或详情「⋯」取消。失败时可查看脱敏详情、重试或进入相关设置；已有译文后，可从「⋯」重新翻译。目前不提供单独删除译文的操作，避免连同原文一起删除。

全文翻译从 0.9.3 起可用；0.9.6 中阅读器的全文翻译已切换为下述块级流程。文献库、书桌与多选的兼容任务入口暂时保留原有流程；已有译文仍可阅读。

### 块级翻译（0.9.11）

已有块译文时，阅读模式中可选「原位」：中文直接显示在原论文的文字区域，尚未翻译的块保留原文。题名和图注也会覆盖，图、表与公式保留原图。译文采用衬线字体，按区域缩小到原字号的 65%；仍放不下时省略，悬停可看全文，或点「展开译文」打开块卡片。

按住 **Alt** 临时显露原文，松开恢复；单击段落切换该块的原文／译文。拖选仍选中原文，选择期间临时显露原文；批注工具激活时同样显露原文，按 V 恢复选择工具，之后可照常批注、做闪卡或问 AI。引用链接沿用原文位置。白纸、米色、夜间三种纸色均支持。

右侧「译文」页跟随当前阅读页，按顺序列出各块；悬停对应原文区域，单击定位并打开卡片。可逐条复制、复制本页译文，或点「翻译这一块」补翻。单块任务与全文任务可以同时存在。

块卡片打开时，**↑／↓** 切换前后块，必要时自动跳页；关闭卡片后恢复页面滚动。块模式下单击图表，或在卡片点「放大」，打开矢量裁剪查看器；支持滚轮／按钮缩放、拖动、图内标签开关，**Esc** 关闭。设置 → 翻译中的图内文字开关同时控制原位叠加及查看器的默认状态。

原位显示不改写原 PDF，也不改变下载的重排译文 PDF。跨栏／跨页译文按各段区域容量分配，未做逐句对齐；极密版式和过长译文建议结合侧栏或重排译文阅读。


在阅读器顶部点击「翻译全文」，ReadFlow 会先在本机分析 PDF 的文字层和页面区域，再翻译需要的文字块，最后生成 A4 单栏译文 PDF。图表和独立公式保留矢量内容；可识别的图内文字可叠加译文，参考文献和作者默认保留原文。顶部显示提取、翻译、排版进度；可以取消，已完成的块译文会保留以供续翻。

想按段阅读时，打开工具栏「块模式」。已有当前语言的块译文时会自动开启；没有译文时保持关闭。手动关掉会作为全局偏好记住，首次进入可关闭操作提示。开启只做本地分析，不会自动发起翻译：悬停可看边界，单击一个块打开译文卡，没有译文时再点「翻译这一块」。图和表显示关联的图注译文，以及「图内文字」对照列表；数字、单位、坐标轴刻度和公式类标签保留原样。卡片可复制、加入笔记／画布／闪卡，也可查看原文或重新翻译。拖动仍然是选中文字，批注工具、引用跳转和快捷键仍可使用。

在「设置 → 翻译 → 块级翻译」选择目标语言，默认中文。翻译服务和启用的术语表与选段翻译共用；只有明确点击翻译才发送相应文字。相同块、语言、服务、模型和术语表的成功结果会复用。修改单块译文后，点「补翻／重新排版」更新整篇译文 PDF。

**翻译提速**：在「设置 → 翻译」可以调整并发数，并选择「翻译时关闭模型思考（更快、更省）」。关闭思考默认开启，只向确认支持的 DeepSeek 官方地址发送；其他服务不会收到未知参数。不支持的服务会自动兼容重试并显示说明。AI 伴读和 AI 出题不受此开关影响，修改开关也不会清空已有译文缓存。

未保存过并发数时，DeepSeek 默认 8，其他服务默认 4；保存过的数字继续使用，超过 16 则限制到 16。所有翻译任务共用上限，若同时任务使用不同设置，以其中较小值为准。遇到服务限流会自动减半并稍后重试，连续成功后逐步恢复；并发越高不一定越快，应结合服务额度调整。修改并发数后点「保存」。

从阅读器发起全文翻译，会先处理当前页和后两页，再按原顺序补翻其他页面。每批成功后即可在块模式查看译文，不必等到全文结束；全部翻译完成后显示「正在排版译文 PDF」，此时已完成的块仍可阅读。取消会中止尚未完成的请求，已保存的批次保留，方便下次续翻。

0.9.9 改善了不同论文版式的拆块。算法伪代码和代码清单按矢量裁剪保留；定理、定义及表注仍可翻译，数学片段保留。升级后点「补翻／重新排版」应用新分类，已有正文缓存继续复用；复杂图表和无规则题注仍建议对照原文核对。

完成后可切到「译文」或「对照」。新译文采用内置思源宋体、A4 单栏重排，因此页码与原文不一定一一对应；对照仍按同页号同步，可关闭同步后分别滚动。原有兼容任务生成的译文在没有新结果时继续使用；有历史译文的阅读器可通过「翻译全文（块级）」生成新版。

在「导出译文」菜单可下载译文 PDF；其中「导出 LaTeX 工程」下载一个 ZIP，包含 xeCJK 模板与矢量图表、公式文件。导出的工程供具备 XeLaTeX 环境的用户后续编辑；日常翻译与阅读不需要安装 TeX。

0.9.7 已内置 CPU 版面模型和 OCR，无需另行下载。系统优先使用 PDF 文字层；扫描页或文字很少的页面在本机识别，位图中的文字也会补充识别。版面和识别结果按页缓存。行内上下标按字号和基线还原；复杂表格、跨栏阅读顺序、图注关联及复杂数学的结构仍可能需要人工核对；原文件始终保留。译文排版字体设置继续用于兼容任务，新块级排版本阶段固定使用内置思源宋体。

在「设置 → 翻译」可关闭「译文 PDF 中翻译图内文字」。开启时在原图副本上添加半透明文字框；放不下的标签仍显示原文，源 PDF 不会被修改。关闭后重新排版即可恢复原图展示。

翻译请求带论文题名和当前章节以保持术语一致。服务返回格式异常时会针对缺失块重试；请求过于频繁时会稍等重试，可随时取消。任务顶部的「本次约 N tokens」来自服务返回的用量，不是费用账单；服务未返回用量时不显示。

### 续读与批注

翻页后阅读进度会自动保存，再次打开同一篇文献时从上次页码继续。首次打开未读文献会进入「在读」状态；需要标为已读或重新标为未读时，在详情的「⋯」菜单操作。

在 PDF 中选中文字后使用阅读器的批注工具，可保存引文、颜色和想法。批注会同步到详情笔记卡片、笔记空间和书桌「最近批注」。点击批注的「在阅读器中打开」可回到原文页码；批注页码以原 PDF 为准。

在笔记空间修改批注正文后，若已经打开的阅读器尚未显示新内容，点击「在阅读器中打开」重新进入该页即可。

## 书桌

书桌显示日期与当天的阅读、批注小结；库为空时先展示欢迎页。

| 区域 | 用途 |
| --- | --- |
| 快速开始 | 导入文献、本地 OCR、翻译 PDF、AI 伴读、有笔记的文献、术语表 |
| 继续阅读 | 最近阅读的三篇文献及已保存的进度；点击继续阅读 |
| 翻译 | 查看进行中的任务、排队数、已译篇数及最近完成的文献；选择一篇进入阅读器 |
| 最近批注 | 回看最近的引文，点击回到原文页面 |
| 待读 | 从待读清单打开文献 |
| 文献库概览 | 文献、已译、分组数量；自由笔记和批注分别按条计数；跳到缺 DOI、缺中文题名、需要 OCR 的文献 |

没有待处理项时，概览显示「一切就绪」。某项数据为空时，小组件会显示对应提示。

## 笔记

点击侧栏顶层「笔记」进入笔记空间。左栏可搜索正文、引文和文献题名，切换「全部／笔记／批注」，并按今天、昨天、过去 7 天、更早浏览。

选中一条后在右侧编辑 Markdown，点击「预览」查看排版。正文使用普通字体；支持标题、列表、引用、代码等 Markdown 内容。原始 HTML 会作为文字显示，不会执行，链接只允许网页与邮件地址。

- **新建**：点「新建笔记」或按 `Ctrl N`。已按文献筛选时直接为这篇新建，否则先搜索、选择所属文献。
- **自动保存**：停止输入约 0.8 秒后保存。看到「已保存」后即可放心退出；保存失败时保留当前输入并提供重试。应用内切换前会先尝试保存。新建空白草稿需输入正文才会保存。
- **批注正文**：引文与原页码显示在正文上方；可编辑自己的说明，点击页码入口回到阅读器。
- **删除与复制**：工具栏提供删除确认和「复制为 Markdown」。删除已保存的笔记无法在笔记空间撤销，请先确认。
- **导出**：顶部「导出为 Markdown」下载当前筛选结果，按文献分节，批注附页码。笔记导出不能替代整个文献库的备份。

在文献详情的「笔记」卡片中，可查看最近三条、直接新建，或点击「查看全部 N 条」进入该文献的笔记。编辑器上方的文献名称可返回文献库并选中它。

侧栏「笔记」总数包括自由笔记和批注；书桌概览将两种记录分别计数。这与「有笔记的文献」的篇数不同。

## 设置

侧栏底部齿轮菜单选择「设置…」，或按 `Ctrl ,`。完成后点击「完成」返回工作台。

| 分类 | 快捷键 | 操作 |
|---|---|---|
| 通用 | `Ctrl K` | 打开命令面板 |
| 通用 | `Ctrl /` | 键盘快捷键 |
| 通用 | `Ctrl ,` | 打开设置 |
| 通用 | `Ctrl 1` | 打开书桌 |
| 通用 | `Ctrl 2` | 打开文献库 |

## 字体与文字大小

打开「设置 → 通用 → 字体与文字」。界面字体提供四种预置：默认（Inter + 思源黑体）、思源黑体、衬线、楷体。选择后立即应用，并显示「ReadFlow 文献管理 · Bilingual Reading 2026」预览。

在桌面版中，选择「其他已安装字体…」可以搜索、选择本机已有的字体，列表会标出支持中文的字体。这个过程只读取字体名称与语言支持信息，不会下载字体；字体安装或移除后可点「刷新字体」。普通浏览器只提供预置项。预置所需字体未安装时，会使用系统回退字体；此前选择的本机字体被移除时，也会回退显示。

文字大小有 **85%、90%、95%、100%、110%、120%、130%** 七档，默认是 100%。调整会立即作用于整个工作台，列表行会变高或变矮；窄窗口中长题名仍会截断，悬停可查看全文。「恢复默认」只将文字大小恢复到 100%，保留字体选择。

笔记编辑器另有「跟随界面／衬线／等宽」三种选择，字号跟随全局文字大小。设置会在本机保存，并在同一工作台地址的多个标签页或窗口之间同步，重新打开后保留。

工作台中的阅读器会同步工具条、Markdown／AI 面板及批注浮层的界面字体与字号。**PDF 页面不使用这些界面字体设置**，它仍由阅读器自身的缩放控制。

- 在工作台中，`Ctrl =` 增大文字、`Ctrl -` 缩小文字、`Ctrl 0` 恢复默认文字大小；也可以在命令面板中搜索「文字」。
- 在阅读器标签内，上述三个快捷键控制 PDF 的放大、缩小、重置，不会更改工作台文字大小。
- 「设置 → 翻译 → 译文排版字体」控制之后新生成的译文 PDF，和界面字体是两个独立选项；更改不会重新排版已经生成的文件。设置会持久保存。

## 新阅读器

文献在工作台原生标签页打开，支持连续滚动、目录、缩略图、书签与全文搜索。内部引用和图表可悬停预览；跳转后用后退返回精确阅读位置。工具栏可切换原文、对照或译文，缺少译文时先发起全文翻译。夜间、米色和专注模式可独立选择，阅读位置自动保存。

## 批注工作台

选择文字后直接点语义色创建高亮；工具栏提供下划线、便签、框选截图、手写和按笔画擦除。语义色默认对应重要、方法、结果、疑问和术语，可在设置改名。右栏按颜色、类型、本页、有说明或有闪卡筛选，支持导出 Markdown、整理成笔记。撤销仅针对当前会话。

## 思考画布

在侧栏新建课题画布。选段、已有批注或整篇文献可加入画布，与自己的想法、问题、分组框和连线一起整理。阅读器可文献与画布分屏；摘录来源链接可回原文，原文角标可反查画布。用空格拖动平移、Ctrl 滚轮缩放；导出 Markdown 提纲便于撰写综述。

## 选中即译与 AI

选取原文后点「翻译」或 T，使用翻译设置中的服务，可复制或保存为批注说明。「问 AI」会带上选段，首次发送列出题名、摘要、本页和选段的发送范围。只有确认发送才调用服务；回答中的页码可点回原文，也可保存为笔记或加入画布。发送失败时问题留在输入框中，方便重试。

## 闪卡与复习

选中文字后点「做成闪卡」或 C，也可从批注菜单或画布摘录卡进入。选择问答、填空或术语卡型；填空在原文中选词后点「挖空」。填写正面、答案、我的解释，选择或新建卡组，必要时关联文献分组、添加标签。已有译文会带入；对应页译文需要自行删减核对。保存时自动创建高亮或关联已有批注。

侧栏「复习」和书桌「今日复习」显示可学习卡数。先思考，再按空格看答案，按 1–4 选择重来、困难、良好或简单；按钮显示下一间隔。O 回到原文。离开后学习进度保留。「重来」在本轮继续出现；每天凌晨 4 点切换学习日。默认新卡 20、复习 200，在设置通用页调整。

管理列表可搜索、编辑、暂停、删除和导出 CSV。删除批注时须选择保留关联闪卡为静态卡，或一并删除。卡片不会自动联网出题，复习无需模型服务。

## 隐私与联网

- 文献、附件、笔记、批注、画布、闪卡和阅读记录保存在本机，本版没有自动云同步。
- 只有在你配置翻译或 AI 服务并主动使用相关功能时，所选内容才会发送到你配置的服务。「检测接口」也是一次主动请求。
- 默认 OCR 随应用提供，不下载；兼容可选模块只在确认后下载。识别始终在本机 CPU 运行。
- 导入本地 PDF、整理分组、阅读原文和编辑笔记不需要模型服务。Connector 抓取在线网页或 PDF、打开外部链接时会访问相应网站。

## 已知限制与常见问题

**为什么有文献却打不开 PDF？** JSON 导入可能只有书目信息，未带可用附件。请先导入对应 PDF；加密、损坏或不支持的文件也可能无法打开。

**扫描件不能选中文字怎么办？** 在「本地 OCR」确认内置模块就绪后运行识别；阅读器块级翻译也会自动识别缺字页面。OCR 主要为检索、翻译和问答提供文本，不保证修改原 PDF 的文字层或完美还原复杂版面。

**翻译或 AI 无响应怎么办？** 检查所选服务、URL、模型与额度，必要时主动检测接口。未配置服务时只能使用不依赖模型的功能；应用不会替你申请账户。书桌的翻译状态只是当前已知状态，不代表已经提交整库翻译。

**出现「无法连接本地文献服务」怎么办？** 应用会自动重试，也可点提示条的「重试」。仍未恢复时，在确认已保存的内容后完全退出并重新打开。不要通过删除数据目录解决连接问题。

**出现「出了点问题」怎么办？** 使用「复制诊断信息」保存错误说明后点击「重新载入」。诊断用于定位程序错误；分享问题时无需提供文献、配置或凭据文件。

**能否批量翻译、永久清空回收站或直接同步 Zotero？** 多选文献后可点击「翻译所选」。暂不提供永久清空回收站或直接同步 Zotero；可在回收站恢复条目，通过 JSON 或 Connector 导入。JSON 导入不会迁移 Zotero 的完整插件状态或文字处理器引用关系。



## 0.9.6 补充

- 夜间阅读会保留 PDF 位图的原色；矢量图仍可能反色。复杂透明图片按绘制区域恢复，边缘内容可能一起保留原色。
- 制卡时点「让 AI 出题（会发送这段文字）」，确认发送范围后生成正面与背面建议。它使用 AI 伴读的服务与本文会话，不会自动保存卡片。核对、修改后再保存。
- 画布工具栏「导出 PNG」保存全部内容；先选择需要的浅色或深色外观。大画布会缩小到最长边 8192 像素、1600 万像素以内。
- PDF 导入会读取文件中的作者、明确的摘要或描述、关键词；没有可靠元数据时仍留空，可在文献库自行补充。

### PDF 导入时的离线信息补全

若 PDF 没有有效题名，ReadFlow 会快速分析首页的题名与作者区；只填写可靠的结果。Anonymous Submission 等占位作者会被忽略。识别到 arXiv 编号后，自动补入 arXiv 链接、DOI、出处与年份，年份使用 arXiv 编号对应的首次提交年份，不使用最新版本的水印日期。整个过程不联网。

已有文献不会静默修改。在详情面板的「信息」区域核对每个字段的原值和建议值，再点「使用 PDF 中识别的信息」。只替换文件名题名和空／占位作者，DOI、URL、日期和出处只补空值；有效字段不覆盖。低置信度时不提供替换，扫描件和复杂作者排版可能需要手动填写。以前导入的非空日期如需纠正，请手动编辑。

元数据题名里的常见 TeX 命令会转换成可读字符，例如 `$\pi_0$` 显示为 `π₀`；复杂 TeX 仅保留文字，不会执行。
