# ReadFlow 使用说明

适用于 ReadFlow 0.9.0 Linux 桌面版。

## 安装、启动与卸载

本版安装包适用于 x86_64 的 Debian／Ubuntu 系发行版。进入安装包所在文件夹，在终端运行：

```sh
sudo apt install ./readflow_0.9.0_amd64.deb
```

安装后从应用菜单打开 **ReadFlow**，也可以在终端运行 `readflow`。若安装器提示缺少系统依赖，请按提示补齐；离线安装需预先具备这些依赖。

ReadFlow 与旧版 RetainPDF 使用不同的应用名称、安装目录和数据目录，可以并存。ReadFlow 不会自动搬移旧版的文献或设置；请通过导入功能加入所需资料。

关闭窗口通常会收起到系统托盘；要完全退出，请在托盘菜单选择「退出」。卸载前先完全退出，再运行：

```sh
sudo apt remove readflow
```

卸载软件不会主动删除个人文献和设置。升级或卸载前建议按下文备份。

## 第一次打开与导入

空库会显示欢迎页。你可以直接导入资料，也可以先设置翻译服务；整理文献和阅读原文不需要模型账户。

### PDF

点击欢迎页的「导入 PDF…」，或文献库工具栏的「+ → PDF 文件…」，选择一个或多个 PDF。也可以把 PDF 拖到窗口任意位置，看到「松开以导入 N 个 PDF」后松开。非 PDF 文件不会导入。

导入完成后在文献库选中条目，检查题名、作者等信息；PDF 没有完整元数据时，可在详情面板补充支持编辑的字段。扫描件可以先阅读，再按需执行本地 OCR。

### Zotero / CSL JSON

1. 在 Zotero 中选中文献并导出为 **CSL JSON**；也支持包含条目列表的 Zotero API JSON。
2. 在 ReadFlow 选择「+ → Zotero / CSL JSON…」，打开该文件。
3. 查看导入预览中的文献、分组、标签和笔记数量及警告，再点「确认导入」。

JSON 中没有提供的信息不会凭空补齐；CSL JSON 通常以书目信息为主。JSON 引用的本机附件路径不会自动复制 PDF，请另行导入需要阅读的文件。同一来源重复导入会按来源标识更新；请保持来源文件名稳定。大文件可分批导出（单次最多 5,000 条、16 MiB）。

### Zotero Connector

Connector 是浏览器扩展，需要自行安装。本版提供实验性的本地接收能力，但普通启动默认没有开启接收端口，设置中也没有启用开关。

如需试用，先完全退出 ReadFlow，确保 Zotero 没有占用本地接收端口，再在终端启动：

```sh
RETAIN_PDF_RESEARCH_CONNECTOR_PORT=23119 readflow
```

之后在浏览器文献页面点击 Connector 的保存按钮。支持的页面会保存书目信息，并在可用时附带 PDF；保存后可在文献库查看。这个启动方式仅对本次运行生效。不要为此结束或覆盖其他正在使用该端口的软件。

Connector 兼容范围有限，不等同于完整 Zotero：网页快照、站点附件解析器及文字处理器引用集成等尚未支持。若显示未连接或某个站点保存失败，使用 CSL JSON 和 PDF 导入即可。ReadFlow 不提供 Zotero 云同步。

## 文献库

侧栏提供全部文献、待读、星标、最近阅读、未分组、**有笔记的文献**和回收站；部分空分类会隐藏。「有笔记的文献」按篇计数，包含有自由笔记或批注的文献。

- **分组**：支持子分组，一篇文献可加入多个分组。拖动选中的文献到分组即可加入；也可按 `G` 选择分组。分组的「⋯」或右键菜单可新建子分组、重命名、删除。删除分组不会删除文献。
- **标签与星标**：点击侧栏标签筛选；在详情中维护标签，用星标标记重点文献。标签较多时点击「更多」。
- **排序与显示**：工具栏可按添加时间、标题、年份、作者、出处升降序排列。「显示」菜单切换双语／紧凑密度，以及列表／按分组布局；按分组时，多组文献会在每个所属分组中各出现一次。
- **搜索**：搜索会筛选当前视图，可匹配中英文题名、作者、DOI、出处、引用键和标签。工具栏显示当前筛选及结果数量，点击清除按钮取消筛选。
- **多选**：`Ctrl` 单击逐个选择，`Shift` 单击连续选择；详情区会显示批量操作。
- **详情**：查看摘要、分组和信息，编辑中文题名、出处、引用键等；可复制参考文献或 BibTeX、导出 Markdown，并查看最近笔记。
- **回收站**：删除操作会把文献移到回收站，之后可以恢复。0.9.0 工作台没有永久清空回收站入口。

双击文献或按 `Enter` 打开阅读器。长题名被截断时，将鼠标停在题名上可查看全文。

## 阅读、翻译与批注

每篇文献在工作台中打开一个阅读器标签；切换标签不会重置当前阅读位置。阅读器跟随工作台的浅色／深色设置，PDF 纸张保持原来的颜色。

### 原文与译文

在「设置 → 翻译」保存服务配置后，在阅读器中主动开启实时译文或使用其翻译操作。阅读器支持原文、译文和对照视图；具体模式取决于该文献是否已有可用译文。详情中的「对照阅读」也会打开阅读器，可在其中选择对照模式。

书桌「翻译 PDF」会先让你选择文献，再进入阅读器。**全文翻译目前在阅读器中进行，一键批量翻译尚未提供。** 保存服务配置不会自动翻译文献。

### 续读与批注

翻页后阅读进度会自动保存，再次打开同一篇文献时从上次页码继续。首次打开未读文献会进入「在读」状态；需要标为已读或重新标为未读时，在详情的「⋯」菜单操作。

在 PDF 中选中文字后使用阅读器的批注工具，可保存引文、颜色和想法。批注会同步到详情笔记卡片、笔记空间和书桌「最近批注」。点击批注的「在阅读器中打开」可回到原文页码；批注页码以原 PDF 为准。

在笔记空间修改批注正文后，若已经打开的阅读器尚未显示新内容，点击「在阅读器中打开」重新进入该页即可。

## 书桌

书桌显示日期与当天的阅读、批注小结；库为空时先展示欢迎页。

| 区域 | 用途 |
| --- | --- |
| 快速开始 | 导入文献、本地 OCR、翻译 PDF、AI 伴读、有笔记的文献、术语表 |
| 继续阅读 | 最近阅读的三篇文献及已保存的进度；点击继续阅读 |
| 翻译 | 查看进行中的任务、排队数、已译篇数及最近完成的文献；选择一篇进入阅读器 |
| 最近批注 | 回看最近的引文，点击回到原文页面 |
| 待读 | 从待读清单打开文献 |
| 文献库概览 | 文献、已译、分组数量；自由笔记和批注分别按条计数；跳到缺 DOI、缺中文题名、需要 OCR 的文献 |

没有待处理项时，概览显示「一切就绪」。某项数据为空时，小组件会显示对应提示。

## 笔记

点击侧栏顶层「笔记」进入笔记空间。左栏可搜索正文、引文和文献题名，切换「全部／笔记／批注」，并按今天、昨天、过去 7 天、更早浏览。

选中一条后在右侧编辑 Markdown，点击「预览」查看排版。正文使用普通字体；支持标题、列表、引用、代码等 Markdown 内容。原始 HTML 会作为文字显示，不会执行，链接只允许网页与邮件地址。

- **新建**：点「新建笔记」或按 `Ctrl N`。已按文献筛选时直接为这篇新建，否则先搜索、选择所属文献。
- **自动保存**：停止输入约 0.8 秒后保存。看到「已保存」后即可放心退出；保存失败时保留当前输入并提供重试。应用内切换前会先尝试保存。新建空白草稿需输入正文才会保存。
- **批注正文**：引文与原页码显示在正文上方；可编辑自己的说明，点击页码入口回到阅读器。
- **删除与复制**：工具栏提供删除确认和「复制为 Markdown」。删除已保存的笔记无法在笔记空间撤销，请先确认。
- **导出**：顶部「导出为 Markdown」下载当前筛选结果，按文献分节，批注附页码。笔记导出不能替代整个文献库的备份。

在文献详情的「笔记」卡片中，可查看最近三条、直接新建，或点击「查看全部 N 条」进入该文献的笔记。编辑器上方的文献名称可返回文献库并选中它。

侧栏「笔记」总数包括自由笔记和批注；书桌概览将两种记录分别计数。这与「有笔记的文献」的篇数不同。

## 设置

侧栏底部齿轮菜单选择「设置…」，或按 `Ctrl ,`。完成后点击「完成」返回工作台。

| 分类 | 可以设置什么 |
| --- | --- |
| 通用 | 跟随系统／浅色／深色、双语／紧凑列表、启动显示书桌／文献库 |
| 翻译 | 服务、API URL、模型、API Key、并发数；保存后供阅读器及翻译任务使用 |
| 本地 OCR | 查看模块名称、版本、模型、大小和就绪状态；刷新、安装、移除 |
| AI 伴读 | 运行模式、操作确认方式、问答模型或 Gateway 配置 |
| 术语表 | 新建、编辑原文与译文条目、CSV 导入与导出、删除及选择默认术语表 |
| 文献库 | 查看统计，从 Zotero / CSL JSON 导入 |
| 关于 ReadFlow | 版本、开源与字体许可、打开旧版界面 |

### 翻译服务

填写服务提供方给出的地址、模型和凭据后点「保存」。已有 Key 默认遮罩，旁边显示「已配置」；仅在点击「显示」时显露，失焦或切换分类后重新遮罩。

「检测接口」只在点击时向所选服务发送一次很小的请求，可能计入该服务用量。保存本身不会触发检测。模型名称、可用额度和并发限制以你使用的服务为准。

### 本地 OCR

优先利用 PDF 已有文字层，只识别缺字页面。未安装模块时，点击「下载并安装…」，核对来源、大小后再次确认才开始下载；若当前环境禁止下载，会显示原因。

模块就绪后，从书桌「本地 OCR」选择需要识别的文献，点击「开始 OCR」。OCR 在本机运行，不需要翻译服务的 Key。移除模块前也会确认；移除后再次识别需要重新安装。

### AI 伴读

从书桌入口选择文献，再在阅读器右侧使用 AI 问答。需要运行本地 AI 服务并配置模型凭据；正式桌面版会随启动开启本地服务。若显示「本地 AI 服务未运行」，可点击重试；浏览、笔记等不依赖 AI 的功能仍可使用。

可选择 Markdown 检索问答、OpenAI 兼容 Agent 或 FX Gateway Agent；未使用的模式无需配置。在问答模型下点「使用翻译配置」可以填入现有翻译配置，之后仍需保存 AI 设置。

「需要确认」会在受支持的 PDF 操作应用前让你确认；「绿灯模式」允许直接执行并应用这些操作，不提供任意系统命令执行能力。切换运行方式可能短暂重启 AI 服务，请等待设置页显示生效。

### 术语表与外观

术语表可逐行维护「原文 → 译文」，也可从 CSV 导入；一次选择一个默认术语表。翻译前选好术语表，有助于统一术语。不同阅读或翻译功能是否采用术语表，以该功能的实际支持为准。

外观在「通用」中设置，也可以用齿轮菜单快速切换。工作台中的阅读器会立即同步明暗；旧版独立页面保留自己的外观设置。

## 数据位置与备份

默认个人数据位于 `~/.config/ReadFlow`。若你另行指定了用户数据目录，以指定位置为准。

| 位置（相对于该目录） | 内容与备份建议 |
| --- | --- |
| `data/research-library/library.sqlite3` | 文献元数据、分组、笔记、批注和阅读状态的数据库；必须备份 |
| `data/research-library/blobs/` | 文献库保存的 PDF 附件；必须与数据库一起备份 |
| `data/research-library/` 中其他文件 | 库标记、数据库伴随文件、OCR 数据等；推荐保留整个目录 |
| `data/research-library/optional-ocr/` | 已下载的 OCR 模块、模型及下载缓存；保留可免于再次下载，可在设置中管理 |
| `data/db/`、`data/jobs/`、`data/uploads/`、`data/downloads/` | 翻译任务记录、原件及生成结果等；需要保留历史成果时一起备份，不应一律当作缓存删除 |
| `desktop-config.json`、`Local Storage/` 及其他配置目录 | 服务配置、界面偏好等；完整迁移时一并保留 |
| `Cache/`、`Code Cache/`、`GPUCache/` | 界面运行缓存，可以重新生成，不是文献库 |
| `data/typst-package-cache/` | 排版依赖缓存；离线使用时建议保留 |

**最简单的完整备份方式**：等笔记显示「已保存」，从托盘完全退出 ReadFlow，再复制整个 `~/.config/ReadFlow` 到备份位置。不要在应用仍写入时只拷贝单个数据库文件。

恢复时先退出应用并保留当前目录的副本，再将备份放回原位置。备份可能包含服务凭据，请像保管账户配置一样妥善保存。旧版 RetainPDF 的目录不属于 ReadFlow 的备份范围。

## 隐私与联网

- 文献、附件、笔记和阅读记录保存在本机，本版没有自动云同步。
- 只有在你配置翻译或 AI 服务并主动使用相关功能时，所选内容才会发送到你配置的服务。「检测接口」也是一次主动请求。
- OCR 模块只在确认后下载；识别过程在本机运行。
- 导入本地 PDF、整理分组、阅读原文和编辑笔记不需要模型服务。Connector 抓取在线网页或 PDF、打开外部链接时会访问相应网站。

## 已知限制与常见问题

**为什么有文献却打不开 PDF？** JSON 导入可能只有书目信息，未带可用附件。请先导入对应 PDF；加密、损坏或不支持的文件也可能无法打开。

**扫描件不能选中文字怎么办？** 在「本地 OCR」中安装并运行识别。OCR 主要为检索、翻译和问答提供文本，不保证修改原 PDF 的文字层或完美还原复杂版面。

**翻译或 AI 无响应怎么办？** 检查所选服务、URL、模型与额度，必要时主动检测接口。未配置服务时只能使用不依赖模型的功能；应用不会替你申请账户。书桌的翻译状态只是当前已知状态，不代表已经提交整库翻译。

**出现「无法连接本地文献服务」怎么办？** 应用会自动重试，也可点提示条的「重试」。仍未恢复时，在确认已保存的内容后完全退出并重新打开。不要通过删除数据目录解决连接问题。

**出现「出了点问题」怎么办？** 使用「复制诊断信息」保存错误说明后点击「重新载入」。诊断用于定位程序错误；分享问题时无需提供文献、配置或凭据文件。

**能否批量翻译、永久清空回收站或直接同步 Zotero？** 0.9.0 暂不提供这些入口。请分别在阅读器翻译、在回收站恢复条目、通过 JSON 或实验性 Connector 导入。JSON 导入不会迁移 Zotero 的完整插件状态或文字处理器引用关系。

**能否回到旧界面？** 齿轮菜单或「关于 ReadFlow」中选择「打开旧版界面」。它使用同一应用内的服务配置，但保留旧版的布局和使用方式；上游更新提示不是 ReadFlow 的发布渠道。
