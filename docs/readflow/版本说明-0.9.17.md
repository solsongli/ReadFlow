# ReadFlow 0.9.17

本版修复原版式译文中的引用链接框错位，以及文字删除后留下的局部下划线或删除线。这两类问题在 0.9.15 和 0.9.16 中也存在。

- **链接随译文移动**：对实际替换区域内的链接，在所属块的中文文字中唯一定位引用、图表编号或链接文字，移动矩形并保留原目标、颜色和边框样式。重复、跨行或缺失而无法可靠定位时，保持原区域和跳转目标，隐藏可见边框；未替换区域的链接保持原样。
- **引用保护**：除引用列表外，Fig./Figure、Table、Eq. 和数字括号也在本地受保护；旧块仅在发送前内存增补，不改变块 ID、既有译文缓存或数学上下标。
- **精确清理装饰线**：仅处理实际替换文字行内的独立水平细路径。结合基线、行高、横向范围排除表格、坐标轴、图形、页眉页脚、外框和公式分数线。局部字母的线不再复制到中文标题。
- **防误删**：先在独立页副本上做仅图形、完全覆盖红删，确认消失的路径都在已判定清单中才提交。发现其他路径损失或变化就丢弃试验，保留原页；原始用户批注不参与清理。
- **增量兼容**：重用页面内容时同时重用修好的链接坐标。layout-audit 记录重锚定、隐藏边框、未受影响及按块类型统计的装饰线数量。

已有块译文可在阅读器「翻译」菜单选择「仅重新排版」应用，无需重新翻译，也不产生模型费用。
本版保留文字可选中、搜索，沿用均衡/紧凑、术语表、质检、图内标签与所有原版式保护。不新增依赖。
