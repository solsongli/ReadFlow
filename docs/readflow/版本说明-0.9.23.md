# ReadFlow 0.9.23

本版修正对照阅读「逐行对齐」译文中的少数异常段落。0.9.21 起就有这些问题，0.9.22 仍未解决。

## 修正

- **散字和碎块**：原文行内有句中粗体、行内公式，或两端对齐造成的宽词距时，旧版把中文切进原文的词槽，导致字号被缩得很小，或者出现「为　了　成功地　将扩　散模　型用　于」这样的大间隙。现在先恢复整条物理行，再按行的基线、左右边界和缩进排版，行内公式等保护片段整体放置。
- **缺字方框**：数学扩展字体中的控制字符在显示时修复，不再出现「☒」。不改译文缓存。
- **段首标题后的空隙**：段首粗体之后，正文连续排下去，不再出现「许　　多工作」这样的空隙。
- **禁则**：补齐中英文弯引号的行首、行尾禁则，右引号不再出现在行首。
- 图注的原文行不会再被误判为表格；需要多一行时使用正常段宽，最小字号不低于原字号的 75%。
- 长西文片段不再被误判为上下标，真正的数学上下标保持不变。

## 维护者验收（2026-10-07）

- 修正内容由 Astra 实现，维护者验收时补了一项：原来的后台修复只处理「缺少逐行版」的情况，用旧排版器生成的逐行版升级后不会更新。现在逐行版记录排版器版本号，版本较旧或缺失时，在本地自动重排一次；已补单测。按页缓存的版本键也已随本版更新，重排不会复用旧页面。
- 离线冒烟脚本中的 `refinement-smoke` 在打包后紧接着运行时，因 2 核负载超时一次；单独重跑两次均通过；整套重跑 31/31 通过。
