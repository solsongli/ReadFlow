# ReadFlow 0.9.2 版本说明

本版合并字体与文字大小设置，以及 0.9.1 的 Zotero Connector 改进。可以从 0.9.0 直接升级，无需先安装 0.9.1。

## 字体与文字大小

- 「设置 → 通用 → 字体与文字」提供默认、思源黑体、衬线、楷体四种界面字体预置，并实时预览。
- 桌面版可选择其他已安装的字体、搜索字体名称，并查看中文支持标记；不会下载字体。普通浏览器提供预置项。
- 文字大小提供 85%、90%、95%、100%、110%、120%、130% 七档，100% 为默认。侧栏、列表、详情、书桌、笔记、设置和菜单即时更新；大库列表随之调整行高。
- 笔记编辑器可选择跟随界面、衬线或等宽字体，字号跟随全局文字大小。
- 工作台中的阅读器同步界面字体和字号，PDF 页面保留自己的字体与缩放。
- 工作台使用 `Ctrl =` / `Ctrl -` / `Ctrl 0` 增大、缩小、恢复默认文字大小；阅读器标签内这三个键控制 PDF 缩放。命令面板也提供文字大小操作。
- 字体偏好会保存，并在同一工作台地址的多个标签页或窗口之间同步。
- 「设置 → 翻译」新增「译文排版字体」，与旧设置共用选择；只影响之后新生成的译文 PDF，不改变已有文件。

## 包含的 Zotero Connector 改进

- 接收浏览器保存默认开启，从应用菜单启动即可使用。
- 「设置 → 文献库 → Zotero Connector」提供持久开关、接收状态和重启入口。
- 端口被 Zotero 或其他软件占用时不抢占、不终止对方进程，文献库照常可用；能够识别时显示占用者。
- 握手页显示简明的 ReadFlow 提示。高级环境变量用法继续保留。

完整操作与兼容范围见[使用说明](使用说明.md)。[0.9.1 版本说明](版本说明-0.9.1.md)保留作历史记录。

## 安装或升级

完全退出 ReadFlow 后，在安装包所在目录运行：

```sh
sudo apt install ./readflow_0.9.2_amd64.deb
```

个人数据继续使用 `~/.config/ReadFlow`。升级前建议按[使用说明](使用说明.md#数据位置与备份)备份。安装包会检查包括 fontconfig 在内的系统依赖；未安装某个字体时，预置会使用其回退字体。
