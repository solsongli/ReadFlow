# 新论文阅读器（0.9.4）

安装 0.9.4 后即可使用。新阅读器在工作台内打开，可多标签切换，并继承界面字体、文字大小和明暗。

- 左侧切换目录、缩略图、书签和全文搜索。没有 PDF 目录时，会尝试识别标题；纯扫描页面需要文字层才能搜索和识别引用。
- 在引用上停留片刻可查看参考条目，跳转、复制或在当前文献库查找。图、表、公式引用提供原文裁图，点击可定位；自动识别和裁图可能不完整。
- 每次目录、引用、图表、搜索或页码跳转都可后退/前进；对照模式分别保留两栏的位置。
- 默认适合宽度，可改适合页面或百分比。Ctrl + 滚轮/触控板捏合以指针所在位置缩放。
- 有译文时选择原文、对照或译文；对照按同页号滚动，缺页一侧停留末页，也可以关闭同步。
- 书签可以命名、删除，并按文献及原/译模式保存。信息栏显示元数据、近似累计阅读时长、最后原文页码和可搜索的参考列表。
- 底色可独立选择白纸、护眼米色或夜间。夜间目前整页反色，图片也受影响；图表预览保持原色。
- `F` 进入专注，只保留页面和细进度条；指针移到顶部可唤出工具栏。再次 `F` 退出。
- 选择文字可复制、复制为作者年份引用，或 GB/T 7714 加页码引用。

常用键：`j/k`、空格/Shift 空格滚动；`gg/G` 到首页/末页；数字加 Enter 跳页；`Ctrl F` 搜索，`n/N` 前后结果；`[/]` 前后章节；`Alt ←/→` 或鼠标侧键返回/前进；`Ctrl Shift C` 复制为引用；`Ctrl =/-/0` 缩放/适合宽度。

画布已在 R3 提供，详见[思考画布](思考画布.md)；AI 已在 R4 提供，详见[选段翻译与 AI 伴读](选段翻译与AI伴读.md)。旧笔记不会删除，旧批注会导入新批注栏；无法可靠恢复位置的旧批注显示引文与页码。

## 批注

- 选择原文后点颜色圆点即可高亮，也可选择下划线或添加说明。五色默认代表重要、方法、结果、疑问、概念；在设置 → 通用 → 批注颜色含义中改名。
- 工具快捷键：V 选择、H 高亮、U 下划线、N 便签、R 框选、P 手写、E 橡皮；1–5 选色。搜索面板有查询时，n/N 保持前后搜索结果功能。
- 便签可放在页边空白，拖动调整位置，悬停查看说明。框选会保存原文区域截图。手写有三档粗细，橡皮按整条笔画擦除。
- 点击批注可改色、编辑说明、复制引文或删除；说明支持简单 Markdown，点“保存说明”提交。
- 右侧批注栏可搜索、按颜色/类型/本页/说明筛选、按页或时间排序。点击条目回到原位；多选可批量改色、删除和导出。
- Ctrl Z / Ctrl Shift Z 撤销与重做本次阅读会话的批注操作，最多保留 50 组。重新打开后的既有批注仍可编辑，但上次会话的撤销历史不保留。
- “导出 Markdown”按颜色含义分节，附页码及文献引用；“整理成笔记”生成可继续编辑的自由笔记。区域图片引用依赖本机文献库，删除原批注会清理截图。
- 对照模式只在原文栏创建和显示批注，译文仍可选择与复制。

R3 调整：批注编辑浮层锚定在原文旁，滚动或切换工具时关闭；新建批注不自动进入多选，两条以上勾选才显示批量栏。筛选改为横向胶囊，排序移入小菜单。
