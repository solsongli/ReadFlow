# ReadFlow 0.9.6

本版提供块级翻译：在原文上点一块看译文，也可生成完整的 A4 单栏译文 PDF。图、表和独立公式保留矢量内容，支持下载 PDF 与导出 LaTeX 工程。

## 块级翻译验收返修（X1b）

1. 全文与单块任务按 scope 分离，同一 PDF 同时最多一个全文任务，重复全文请求复用已有任务。每批只提交成功项增量；锁内重新读取、合并、原子写入缓存，避免并发覆盖。
2. 占位符在本地保存原有左右空白，模型省掉边界空格时会补回，避免 `isxi2`。
3. 根据 span 字号与基线偏移保存本地 `text/super/sub` 结构；Typst 用 super/sub，块卡用 React 的 sup/sub。模型只看到不可改的占位符，不接触其对应内容，也不执行文本中的标记。
4. 首页连续、同字号同字重的多行标题合并，保留原始物理行作为依据。
5. 同栏、同字体且行距正常的图注续行归入图注，字体或段间距变化时停止。
6. 矢量组件按空间连接合并，结合题注和表格横线推断完整区域。主要落在区域内的文字按行移入 figure_text，不进入正文，不发给模型翻译。
7. 对页眉、页脚、侧边及同名斜水印统一做大小写、数字、空白归一化，支持奇偶页换位。
8. 段落保留首行缩进与段前间距信息；跨栏／跨页只延续未结束、无新段落信号的文本。
9. 使用文档内词频恢复断词：已有带连字符形式时保留；确认连写词存在才去掉断行连字符；不确定时保留。
10. 存在当前语言块译文时自动进入块模式，没有译文时保持关闭。手动关闭与首次提示的关闭状态保存到既有安全偏好，跨窗口／重启保留。切换服务后的失败请求不会隐藏该语言已有的成功译文。
11. 单个全文任务内最多两批并行，全服务仍最多两个模型请求；取消中断所有在途请求。进度按完成批次累计，模型请求使用 Simplified Chinese 等语言全称。

## 使用与边界

沿用现有翻译服务、术语表和外部模型开关；任务凭据只在内存中使用，不写入块缓存。读取、提取和自动开启块模式不会调用模型。

提取器升级为 heuristic-3，旧清单会在本地重建，旧译文缓存兼容读取。单块翻译不自动更新整篇 PDF；需点击「补翻／重新排版」。旧版已生成的 PDF 同样需要重新排版才能反映本轮修正。

本阶段没有新增模型、依赖或 OCR；复杂版式及多层行内数学仍需核对。新 PDF 重排后对照按同页号对应，可关闭同步。文献库／书桌兼容任务入口及统计仍保留原流程，新块排版使用内置思源宋体。LaTeX 工程未在本机编译。

ReadFlow 基于 RetainPDF（MIT）开发，保留许可证与上游版权说明。

## 段落连续性返修（X1c）

断词优先续接并沿用文档词频保留复合词；跨图表、图注（含 Scheme）和脚注的半句先还原为完整段落，浮动体随后排出。恢复两端对齐产生的大词间距、同字号字体变体和继承缩进的连续性；真实标题须有字号／字重差异及段后间距。提取器升为 heuristic-3，仅改后端提取／排序及测试，未改前端源码。

| 样例 | text 块数（前→后） | 短块候选（前→后） | 修后未豁免正文碎片 |
|---|---:|---:|---:|
| babeldoc-10p | 78 → 46 | 14 → 8 | 0 |
| yakubenko-halogen-lithium-10p | 86 → 59 | 18 → 11 | 0 |
| s41524-tibetan-plateau-21p | 67 → 47 | 20 → 9 | 0 |

短块候选统一按 text/heading 中 ≤3 词且无句末标点统计，忽略句末引用号。修后保留的 8／11／9 项全是有排版证据的标题，例如 Limitations、General、4 Methods；其字号或字重区别与段后间距保存在 heading_evidence 中。没有未豁免的正文碎片。

真实结构断言覆盖断词后不留下小写续词、图前后续句同属一段且图排在段后、两栏反应叙述和宽词距行顺序不乱，以及所有短标题的豁免依据。三篇新 PDF 已覆盖原 `/tmp/readflow-x1/real-render/` 路径，分别 15／19／17 页，无素材回退；返修前副本、统计和目检图在 `/tmp/readflow-x1c/`。
