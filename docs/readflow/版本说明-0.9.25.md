# ReadFlow 0.9.25

本版对照 Zotero 7 阅读器补齐三项常用能力：全文查找、链接预览和按文献记忆缩放。

- **全文查找**：
  - 结果按实际出现次数计数，支持区分大小写和全词匹配；
  - 输入后立即定位到当前页之后的第一处，显示「1 / N」；`Enter`、`Shift+Enter`（或 `n`、`N`）循环跳转，没有命中时显示「无结果」；
  - 只高亮命中的字符，当前项为橙色，其余为黄色；选字、复制、批注、块模式和对齐辅助线不受影响；
  - 在对照视图中，可选「原文（左侧）」或「译文（右侧）」，结果标明所在侧，逐行对齐的中文页也能查中文。
- **链接预览**：鼠标停在引用编号、图表编号或目录等内部链接上时，显示目标页对应位置的局部画面，并保留复制引用、跳转和在文献库中查找。
- **记忆缩放**：适合宽度、适合页面和 0.2–4 倍的缩放按文献保存，最多记住最近 100 篇，关闭重开或重启后恢复。

以上功能在原文、对照、译文、原位四种视图中都可用。

规划文档新增 Zotero 7 阅读器能力对照表：
- 双页和奇偶跨页、水平和包裹滚动、页面旋转仍缺失；
- 批注标签、批注拖出、系统全屏只部分具备。

37 页 OpenVLA 的滚动帧间隔中位数 16.7ms、P95 50.0ms，不劣于 0.9.19。

本版不新增依赖、模型或网络访问。

## 维护者验收（2026-10-07）

- 离线冒烟 34 个脚本中，33 个整套运行通过；`x16-smoke` 单独运行两次均通过。整套运行时，它的滚动 P95 为 66.7ms，超出 50.1ms 阈值。在 60Hz 下帧间隔只能取 16.7ms 的整数倍，这个阈值恰好等于基线，多一帧就失败。这是断言过严，下一版改为失败时重测一次。
- 用安装包对比 0.9.24 与 0.9.25 的出图时间：同一份只含公开论文的档案，打开 OpenVLA 约 1.4 秒；跳页后原文页 0.1–0.4 秒画出，两版没有差别。
- 已知问题，0.9.24 及更早版本就存在，下一版处理：打开文献后，两份 PDF 会立即在后台逐页提取文字建索引。在 2 核环境中，刚打开就跳页或切到对照时，原文页可能要几秒才画出。下一版改为先画可见页，再建索引。
