# ReadFlow 0.9.10

本版改善 PDF 导入时的题名、作者和 arXiv 信息，并继续处理复杂论文的拆块碎片。本次重新打包包含 X5b 元数据验收修正。

- 元数据题名为空、文件名、arXiv 编号或工具占位时，从首页的字号和连续行识别题名。多行合并，去掉脚注标记；置信度不足时保留原状。
- 过滤 Anonymous Submission、Unknown、Blind Review 等占位作者。只在题名与摘要之间有可靠姓名证据时补全作者；不确定时留空。
- 离线识别文件名或首页的 arXiv 编号，自动填写链接、arXiv DOI、出处和年份。年份取 arXiv 编号中的首次提交年份，忽略水印的版本日期。
- 已有条目不会被批量改写。详情的信息区域逐字段列出建议，点击「使用 PDF 中识别的信息」才应用：仅替换文件名题名、空或占位作者，并补充空的 DOI、URL、日期和出处。已有有效字段保持不变。
- 改善粗体开头、行内数学及字体切换引起的断段；整页实验图中的刻度归入图内文字，图表按列和题注位置确定归属。
- 复数引用「Figs. …」不再误识别为新图注。真实短标题、公式引导语及没有可靠图注的图片仍保留原结构。

首页识别不联网、不运行 OCR 或整篇拆块。扫描件、极不常见的姓名排版可能仍需手动补全。PDF 原文、已保存的题名与作者始终可在信息面板核对。

安装：`sudo apt install ./readflow_0.9.10_amd64.deb`。
