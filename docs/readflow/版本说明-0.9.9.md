# ReadFlow 0.9.9

本版改善不同论文版式的拆块稳定性，重点覆盖机器人、VLA、机器学习及化学、生物论文。

- 修复跨栏图注续行、无额外字体证据的标题分支导致整篇提取失败的问题。
- 补全多种参考文献格式，避免把文献条目和小字号续行当作正文翻译；参考文献之后的附录继续翻译。
- 约束图片的隐形留白，保护图注和另一栏正文；改善多面板图片、跨栏表格、页顶表格以及罗马数字表号的识别。
- 表格保留裁剪图，表题和表注参与翻译。算法伪代码与连续代码清单保留矢量裁剪，不作为普通正文发送。
- 摘要与作者区分开；带框定理、定义、引理保留为正文，数学片段继续受保护。
- 改善 PDF 目录中的复合编号与行内小标题匹配，保留小标题后的正文；没有目录时继续使用标题样式判断。
- 靠近图像的短轴标签更容易归入图内文字，减少正文中的零碎刻度和标签。

## 升级后的使用

原 PDF、已有译文和文献数据保留。新版会重新分析旧块清单，未变化且仍需翻译的块继续使用缓存；需要新版排版时，在阅读器点「补翻／重新排版」。被纠正为参考文献、作者或程序的块会忽略旧误译缓存，按原文保留。

复杂矢量图、没有明确图注的图片、细碎图内标签，以及非常规标题／参考文献格式仍需核对原文。自动检测到的短块不一定是错误，例如公式前的短导语；不会为了降低计数而强行合并。

安装：`sudo apt install ./readflow_0.9.9_amd64.deb`。

## 维护者评估

评估语料为 7 篇公开 arXiv 论文、SafeVLA 与仓库 10 篇跨学科样例。共 18 篇、488 页；166 页样例只取前 40 页，其他样例完整运行。外部语料只读，不复制进仓库。

新增 `ops/development/paper_blocks_corpus.py`，按目录串行提取，使用内置 CPU 版面与 OCR、最多两线程；假译文只由本地回声函数生成，不调用模型或网络。每篇输出块清单、类型／字符统计、诊断指标、假译文 PDF 和逐页对照拼图。

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 nice -n 10 \
  frontend/desktop/linux/linux-unpacked/resources/backend/python/bin/python3 \
  -m ops.development.paper_blocks_corpus \
  --corpus-dir "$READFLOW_CORPUS_DIR" --fixtures tests/fixtures/pdfs \
  --safevla "$READFLOW_SAFE_VLA_PDF" --output /tmp/readflow-x4/after
```

`--no-render` 可用于只跑诊断，`--keep-assets` 可保留中间矢量裁剪。默认清理已嵌入成品 PDF 的中间裁剪，保留指标、推理缓存、PDF 与拼图。每篇由独立子进程执行，仍严格串行；失败独立记录，整批继续，最终有失败时退出码为 1。拼图使用本机已有的 Poppler（pdftoppm），不下载组件，也不增加应用运行依赖。

指标字符数不含空白。原生文字层比例不计参考文献、页眉页脚，并单列额外 OCR 字符；不能用旋转水印的大包围盒扣除其下正文。图中文字另列标签数／字符数。顺序与参考文献边界考虑双栏和跨栏带。短块、孤立题注及无题注图是待目检项，不等同人工标注错误。

render fallback 按排版失败块计；label fallback 按部分标签保留原文的图表块计；translation fallback 按翻译单元计。假译文仅验证拆块、字符保存和排版，不代表真实翻译质量。单栏重排的页码不与原页一一对应，拼图两侧分别标注页码。

外部语料结构测试由 `READFLOW_CORPUS_DIR` 启用，缺语料或内置模型时明确跳过；合成结构、指标口径和原有三篇样例测试始终运行。SafeVLA 的原 294 行覆盖下限未降低，因程序改为裁剪，覆盖口径增加算法／代码源行，其他数学、坐标、附录断言继续保留。

评估中遇到 MuPDF 对假译文 PDF 栅格化／释放时的 native abort；提取与 Typst 排版已成功。保留了日志，改用独立 Poppler 绘制拼图，干净进程复跑通过。此改动只影响评估工具；工作台继续使用 PDF.js。

## 评估结果

18 篇全部通过，488 页。旧版有 4 篇提取失败，现为 0；下表只比较双方均可提取的 14 篇，避免新增样本影响分母。疑似问题可能重叠，不将字符数相加。

| 类别 | 修复前 | 修复后 | 影响论文数（前→后） |
|---|---:|---:|---:|
| 参考文献误入翻译（字符） | 52,816 | 0 | 5→0 |
| 正文误入图像（字符） | 1,815 | 0 | 2→0 |
| 摘要误作作者（字符） | 1,621 | 0 | 1→0 |
| 程序误入正文翻译（字符） | 2,803 | 0 | 3→0 |
| 短文本碎片（块） | 399 | 308 | 11→11 |
| 单行续句碎片（组） | 112 | 57 | 11→9 |
| 孤立图注（块） | 53 | 23 | 12→9 |
| 无图注图表（块） | 97 | 63 | 14→10 |

相同有效目录的 6 篇、199 项：heading 匹配 159→166；新支持的样本及采样文件新保留的书签另见逐篇指标，不混入这个分母。附录正文误判为不可译、同页阅读顺序异常、排版 fallback、翻译 fallback 均为 0。

同 14 篇的 label fallback 为 352→364；全部 18 篇为 433 个图表块。它表示部分图内标签保留原文，图表本身正常渲染；新增图表／标签以及假服务额外前缀会影响该数，不能当作翻译质量分数。

最终回放原生文字覆盖率最低 99.95%，可翻译原生字符比例为 92.75%–99.52%；差额包括有意保留的作者、公式、程序等。按已有版面／OCR 缓存回放，提取平均每页中位数 0.1204 秒，范围 0.0283–2.7345 秒；最慢是图文密集生物论文，后续仍需优化几何与标签处理。不是所有样例的冷启动耗时承诺。

未强行修复：部分图内短刻度、公式导语、原本无题注的小图，以及出版社刊头／目录内容与正文标题的歧义。继续保留原文、指标与示例，避免误合并或丢内容；期刊装饰识别仍有提升空间。

完整指标与审阅入口：`/tmp/readflow-x4/after/index.md`、`summary.json`、`summary.md`；前后对照：`/tmp/readflow-x4/comparison.json`、`comparison.md`。每篇目录中有 `translated.pdf` 和 `comparison-*.png`；总览图为 `/tmp/readflow-x4/overview-01.png` 至 `overview-03.png`。
