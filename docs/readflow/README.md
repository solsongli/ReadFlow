# ReadFlow 0.9.0

ReadFlow 是面向科研的文献管理、双语阅读与笔记工具。它基于 RetainPDF 4.2.5（MIT 许可证）二次开发，把文献库、阅读器、书桌、笔记和设置放进一个工作台。

文献和笔记保存在本机。你可以先导入、整理和阅读 PDF，需要翻译或 AI 伴读时，再连接自己选择的服务。

## 可以做什么

- **整理文献**：导入 PDF、Zotero / CSL JSON；用分组、标签、星标和待读清单组织资料，一篇文献可以属于多个分组。
- **连续阅读**：同时打开多个阅读器标签，记住阅读页码，查看原文、实时译文或对照内容，留下批注。
- **记录想法**：在笔记空间编辑 Markdown、回看批注、按文献筛选，并导出笔记。
- **从书桌开始**：继续上次阅读，查看翻译状态、最近批注、待读清单及需要补全的信息。
- **按需配置**：管理翻译服务、本地 OCR、AI 伴读、术语表和浅色／深色外观。

本版提供 Linux x86_64 的 `.deb` 安装包，可与旧版 RetainPDF 并存。全文翻译仍在阅读器中操作；一键批量翻译尚未提供。Zotero Connector 属于需另行启用的实验性兼容功能。
