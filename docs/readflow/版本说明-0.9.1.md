# ReadFlow 0.9.1 版本说明

本次更新修复从应用菜单启动后无法使用 Zotero Connector 的问题。

- **默认接收浏览器保存**：新安装及从 0.9.0 升级后默认开启 Connector 接收；不再需要通过终端启用。
- **设置与状态可见**：「设置 → 文献库 → Zotero Connector」可开关接收，查看正在接收、端口占用、已关闭或错误状态。
- **偏好持久保存**：切换后重启生效，支持「立即重启」；退出时先清理 ReadFlow 自己的后台服务。
- **端口冲突不影响使用**：Zotero 桌面版或其他软件占用接收端口时，ReadFlow 保留对方进程，文献管理照常可用，并显示可识别的占用者。
- **接收提示更清晰**：浏览器打开本地握手页时显示「ReadFlow 正在接收 Zotero Connector 的保存。」，移除内部验收文案。

高级启动环境变量仍然优先于设置；普通浏览器访问工作台时只能查看接收状态。详细操作、冲突处理和兼容范围见[使用说明](使用说明.md#zotero-connector)。

## 安装或升级

完全退出正在运行的 ReadFlow 后，在安装包所在目录运行：

```sh
sudo apt install ./readflow_0.9.1_amd64.deb
```

这是对同一个 `readflow` 软件包的升级，个人数据继续使用 `~/.config/ReadFlow`。升级前可按[使用说明](使用说明.md#数据位置与备份)备份；无需卸载旧版本。

## 安装包校验

- 文件名：`readflow_0.9.1_amd64.deb`
- 大小：**228,638,068 字节**（约 218.05 MiB）
