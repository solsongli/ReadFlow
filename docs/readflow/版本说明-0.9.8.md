# ReadFlow 0.9.8

本版改善块级翻译速度，并让已完成的译文尽早可读。

- DeepSeek 官方服务的块翻译与选段翻译默认关闭模型思考。可在「设置 → 翻译」关闭此优化；不影响 AI 伴读、AI 出题或已有译文缓存。
- 服务不支持该参数时自动去掉后重试，并显示兼容提示；应用本次运行内记住结果。其他服务不默认发送此参数。
- 并发数默认 DeepSeek 8、其他服务 4。已有设置保留，最多 16；所有翻译任务共用上限，遇到 429 自动降低并发，成功后逐步恢复。
- 从阅读器发起全文翻译时，优先当前页与后两页。每批完成后即可在块卡片查看，全文翻译完成后再排版 PDF。
- 批次按估算输入 token 和并发数拆分，减少尾部等待；仍保留截断拆批、缺失块重试和取消后续翻。

## 使用与限制

并发设置需点「保存」；关闭思考开关立即保存在本地偏好，并作用于随后发起的请求。不同并发设置的任务同时运行时，共用其中较小的上限。429 降速让在途请求完成后再收紧，不会为了降速丢弃已发送的正常请求；主动取消则立即中断本机所有在途请求和退避等待。服务端已经处理的请求仍可能计费。

只对主机名 `api.deepseek.com` 使用已确认的关闭思考参数，不按模型名字推测其他服务能力。服务不提供推理用量时不估算，不承诺固定的真实翻译加速比。文献库与书桌的兼容任务入口仍沿用原有流水线，本版提速针对阅读器块翻译与选段翻译。

批次目标约 2,100 个估算输入 token；保护占位符、论文标题、章节和术语表计入估算。短文为了分散尾部可能更小，单个不可拆的长段及超大术语表可能超过目标。已有块 id、语言和服务指纹不变，本版不要求重新翻译。

## 离线验证

测试使用假服务，没有读取真实密钥或调用真实模型。假服务可用 `--delay-seconds 1.5 --delay-per-kchar 0.5` 配置延迟，`readflow-no-thinking` 模型模拟参数不支持，`readflow-rate-limit` 模拟首次 429。

同一块集清空假缓存，分别运行旧串行、旧双并发与新八并发。测量包含真实等待、请求序列化、占位符往返、结果解析和增量缓存发布；不包含 PDF 提取和最终排版。真实 DeepSeek 性能由维护者另行验收。

复跑命令（仓库根，使用已有 Python 运行时，不访问真实服务）：

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 nice -n 10 \
  frontend/desktop/linux/linux-unpacked/resources/backend/python/bin/python3 \
  -m backend.library_mvp.tests.benchmark_translation_speed \
  --safevla-blocks /tmp/readflow-x2c/final/blocks.json \
  --output /tmp/readflow-x3/benchmark.json
```

SafeVLA 使用已有的公开论文块集副本，不读取用户翻译缓存或配置。665 个翻译单元包括正文、标题、图注以及可翻译的图内标签，因此不等于顶级块数；参考文献、公式等仍按原规则跳过。

独占测量，实际墙钟时间（秒；单元均成功，无模型调用）：

| 块集 | 旧串行：总耗时／首批 | 旧双并发：总耗时／首批 | 新八并发：总耗时／首批 |
| --- | ---: | ---: | ---: |
| 合成论文，47 单元 | 10.498／2.831 | 5.448／2.221 | 5.245／1.673 |
| SafeVLA，665 单元 | 145.362／3.911 | 73.798／1.898 | 17.796／2.129 |

SafeVLA 相对旧双并发约快 4.15 倍，请求数从 56 降为 45；合成短文总耗时收益较小。首批指可供读取的缓存批次，界面另有最多约 800ms 的轮询间隔。新方案优先 SafeVLA 第 4 页与后两页，首批内容与从首页起翻的旧方案不同，不能只凭首批时间判断同一页的等待。关闭思考的真实用量与耗时收益不计入本表。

完整原始数据：`/tmp/readflow-x3/benchmark.json`。截图：`/tmp/readflow-x3/screenshots/`（明暗设置、边翻边读与排版阶段）。

验证：tsc、完整 Web build、Web 334 项、桌面 100 项通过；后端 389 项（388 项常规通过、1 项慢基准单独通过），启动器／假服务 24 项及 CI 约束 3 项通过。取消测试包含真实本地临时端口的连接断开，未使用 23119。新增速度、缓存复用、默认值与兼容性测试全部使用假配置。

安装命令：`sudo apt install ./readflow_0.9.8_amd64.deb`。无需卸载旧版，文献数据保留。
