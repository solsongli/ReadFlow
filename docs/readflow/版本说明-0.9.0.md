# ReadFlow 0.9.0 版本说明

ReadFlow 是面向科研的文献管理、双语阅读与笔记工具。本版提供 Linux x86_64 的 `.deb` 安装包。

## 本版新增

- **统一工作台**：更安静的侧栏、工具栏、文献列表和详情面板；支持系统外观、浅色和深色，双语与紧凑列表，以及按分组浏览。
- **文献整理**：PDF 和拖放导入、Zotero / CSL JSON 导入预览、多级分组、一篇文献属于多个分组、标签、星标、待读与回收站。
- **书桌仪表盘**：快速进入导入、OCR、翻译、AI 伴读、笔记和术语表；查看续读进度、翻译状态、最近批注及待补全的信息。
- **阅读器标签**：在工作台内阅读多篇文献，明暗即时同步，保存阅读进度，再次打开从上次页码继续；批注与文献库联动。
- **笔记空间**：自由笔记与阅读批注统一浏览、搜索和按文献筛选；Markdown 编辑与预览、自动保存、按文献分节导出；详情可直接查看最近笔记。
- **工作台设置**：集中管理翻译服务、本地 OCR、AI 伴读、术语表与偏好。密钥默认遮罩，主动点击后才能显示，失焦后恢复遮罩；保存翻译配置不会自动检测或发起翻译。
- **首次使用与容错**：空库欢迎页、窗口拖放导入、断线提示与自动重试、写入失败重试，以及可复制诊断的错误页面。
- **大库与快捷键**：文献列表按可见范围渲染，保留多选、拖拽、分组和键盘操作；`Ctrl /` 可查看完整快捷键一览。
- **独立桌面应用**：ReadFlow 名称、图标、托盘和独立数据目录。

## 已知限制

- 全文翻译仍在阅读器中操作，暂不提供一键批量翻译。翻译与 AI 伴读需要自行配置服务并主动使用。
- 本地 OCR 模块按需下载，必须确认来源和大小后才会安装；识别在本机运行，复杂版面的准确率取决于文档质量。
- Zotero Connector 为实验性兼容功能，默认未开启接收端口，不支持完整 Zotero 功能或云同步。启用与替代导入方式见[使用说明](使用说明.md#zotero-connector)。
- JSON 导入不会自动读取并复制其中引用的本机 PDF 附件路径，也不会迁移 Zotero 插件状态或文字处理器引用关系。
- 直接导入 PDF 时暂不读取文件元数据中的作者，作者会显示为「作者未知」。需要完整元数据（作者、DOI、出处）时，建议用 Zotero / CSL JSON 或 Zotero Connector 导入。
- 工作台暂不提供永久清空回收站。笔记空间编辑批注后，已打开的阅读器可能需要通过「在阅读器中打开」重新载入该文献。
- 暂无自动云同步。请在完全退出应用后备份整个个人数据目录。

## 版本与数据目录

ReadFlow 使用自己的版本号，提供 PDF 阅读、翻译，以及面向文献整理与笔记的工作台。代码来源和许可记录见[代码来源清单](代码来源清单.md)与根目录许可文件。

ReadFlow 使用独立的个人数据目录，不会自动迁移或覆盖其他应用的文献库。安装包以 [ReadFlow Releases](https://github.com/solsongli/ReadFlow/releases) 为准。

Inter 字体使用 SIL Open Font License（OFL）。项目许可见 [LICENSE](../../LICENSE)，安装后的第三方许可也可在「关于 ReadFlow」查看。

安装、备份及快捷键请参阅[使用说明](使用说明.md)。
