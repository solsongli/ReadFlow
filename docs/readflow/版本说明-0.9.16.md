# ReadFlow 0.9.16

本版改善原版式译文的字号一致性与段落占位，仍保留可选中、可搜索的文字、块级对应、术语表与质检。

- **均衡排版（默认）**：按页、栏和正文/图注/脚注分类规划字号。各段从自己的原位置开始，独立分配行距，短段不会带动后文上移。
- **协调适配**：在原视觉字号以内自然换行，行距最多 1.7 倍；特别长或几何特别紧的区域单独缩小。不会以空行、拉伸字形或过大的字距补足高度。
- **标题与样式**：多行题名优先在语义或词边界换行，保留层级、原字重与颜色，推断原文两端对齐、首行缩进及列表悬挂缩进。段首粗体和上下标保持结构化。
- **中文标点**：利用 MuPDF Story 的中文禁则，对西文括号、百分号等补充短禁换行片段。文本仍先转义，不执行 HTML；保留译文本身的中西文空格，不自动插入细空格，以免改变代码、数字与 URL。
- **兼容**：紧凑密度保留上一版的排版行为。图片、矢量图、独立公式、链接、注释、页码与页面几何保持；图内标签及受影响页增量更新继续可用。

已有块译文可在阅读器「翻译」菜单选择「仅重新排版」应用新算法，无需重新翻译，也不产生模型费用。

## 离线对照

使用现有真实 DeepSeek 译文，仅在临时目录重排，不调用模型，也不修改原资料。
占位比为译文字形包围区域高度/原锚点高度；字号离散度为同页同栏同类正文的平均标准差（pt）；新增空白仅计算正文锚点内的纵向余量，不计原图周围空白。这些几何指标不是像素级美观评分，1pt 字形容差可使占位比稍大于 1。

六张「原文/旧版/新版」拼图与逐页指标在 `/tmp/readflow-x10/`，覆盖 SAM 1/4、OpenVLA 3、Diffusion Policy 2、ACT 2/3 页。四篇共 104 页的页数、MediaBox、CropBox、旋转、图片/矢量图、链接/注释、字形越界及已红删区域残留检查全部通过。

仍可能出现很短的译文或被行内图像切分的窄区域；这类区域保持顶部对齐，不强行制造空白行。ACT 的低分位受这类短区域影响，尽管中位占位和总体空白改善。个别超长译文继续依原有保护缩小或显示省略，全文可在块卡片阅读。
MuPDF 1.26.5 不实现 CSS letter-spacing/word-spacing，本版将字距保持为零。原文本身没有提供的视觉信息只能从文字几何推断，复杂装饰性标题/竖排仍有局限。

本版保留版权与所有第三方许可；无新增模型或依赖。排版原则受 nature-paper-trans 启发，代码与提示词均未复制。
