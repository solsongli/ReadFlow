# ReadFlow 0.9.11

本版增加保留原论文版式的译文读法，并改善逐块阅读和图表查看。

- **原位译文**：在原文／对照／译文旁新增「原位」。只覆盖已翻译的题名、正文和图注；尚未翻译的块、图表和公式保留原文。中文衬线字号按区域自动适配，下限为原字号 65%，过长时省略并可展开全文。
- **随时看原文**：按住 Alt 临时显露原文，松开恢复；单击切换单块。拖选仍操作原文文本层，继续支持批注、闪卡和 AI；批注和引用链接保留在覆盖层上方。
- **译文侧栏**：跟随当前页列出各块，悬停定位、点击跳转、逐条或整页复制，并支持单块补翻。
- **逐块阅读**：块卡片打开时用 ↑／↓ 移动前后块并自动滚动，关闭后恢复原来的页面滚动行为。
- **图表放大**：块模式下单击图表或在卡片中点「放大」。按缩放重新绘制矢量裁剪，支持拖动、译好图注、图内文字开关与 Esc 关闭。
- 支持白纸、米色与夜间纸色。夜间位图原色恢复继续保留；设置中的图内文字开关也控制原位显示。

## 使用限制

原位覆盖是阅读显示层，不会改写原 PDF 或替换下载的重排译文 PDF。跨页／跨栏译文根据各锚点面积分配，并尽量在标点处断开，不是逐句对齐；引用链接仍在原文坐标。密集版式、较长译文可能省略，完整内容可在卡片或侧栏查看。图内标签依赖现有提取位置，复杂图可能需要关闭叠加后核对。

## 实现与验证

覆盖层不接收指针，显示次序为 PDF／原位译文／原文文本与链接／批注。原位译文只在可见区域附近排版；缓冲页保留轻量容器。持续滚动时复用未变化的译文与侧栏，避免重复字体测量。批注工具激活时也会显露原文，按 V 回到选择工具后恢复原位显示。

单元测试覆盖字号下限、溢出、跨锚点文本完整性、上下标、旋转标签坐标、逐块顺序及原文／图注复制。离线场景覆盖部分翻译、纸色、Alt／点击切换、原文拖选与批注、引用跳转及返回、侧栏跟页／悬停／复制、独立单块与全文任务、图表缩放／拖动／标签和 Esc；另跑原阅读器、批注与 X1b 回归。

本地复现素材：先用 `ops/development/reader_inline_fixtures.py --corpus-dir "$READFLOW_CORPUS_DIR" --blocks-root /tmp/readflow-x5/after` 生成隔离的 fake 数据，再在 `frontend/web` 运行 `node --import ./tests/helpers/register-jsx.mjs tests/paper-blocks/inline-smoke.mjs` 与 `inline-corpus-smoke.mjs`。外部原 PDF 只读，未提交进仓库。

## 最终验证与性能

- tsc、Web build、Web 全量 341、桌面 100、后端 437（436 常规＋1 项单独慢测）、启动器／假服务 24、CI 约束 3 全部通过。行宽、可达性、颜色和依赖门禁包含在 Web 测试中。
- 新界面场景及原有 X1b（6 组）、批注（9 组）、阅读核心（11 组）回归通过。模型请求全为假响应，无外部请求或页面错误。补了按下与抬起之间重渲染的图表点击回归，避免轮询或偏好同步丢失点击。
- OpenVLA 37 页，1680×1050、deviceScaleFactor=2、单实例 headless Chrome、禁用 GPU，译文侧栏同时打开。连续扫描 599 个帧间隔：中位 16.7 ms、P95 33.4 ms；36 个间隔超过 33.4 ms（含计时小数边界），无 ≥50 ms 的 JS 长任务。首屏 PDF 621 ms，原位切换 129 ms，最多挂载 4 页／4 个覆盖容器，只有附近页实际排版。
- 更激进的 239 帧扫全篇压力场景：原位 P95 50 ms，原文对照测量 P95 33.4 ms。极速扫页仍有短时掉帧，不能把普通连续滚动数据理解为所有条件恒定 60 FPS；禁用 GPU 的无头测量不等同真实桌面体验。
- 字体适配改为估算后有限次数校准，图内标签使用纯计算；页面及侧栏复用不变内容，块区域独立布局，视口外缓冲容器不做文字排版。初版压力测试的 6 个 JS 长任务（最长 89 ms）已消除。
