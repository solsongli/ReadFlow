# ReadFlow 0.9.14

**本页安装包已包含 X9b 修复。0.9.13 的内部标记泄漏问题已修复，旧缓存无需重新翻译。**

本版增加五项阅读辅助功能，延续 0.9.13 的全文翻译与质检流程。

- **论文速览**：AI 面板与信息面板可生成结构化导读，涵盖动机、方法、实验结果、结论与相关工作。明确确认发送范围后才调用配置的 AI 服务；支持取消、缓存、重新生成、保存为笔记和复制 Markdown。
- **术语悬停**：原文与原位模式中查看已有术语的统一译法、类型、首次出现位置，兼容大小写、常见复数和连字符变体。启用的用户术语优先。
- **图表导航**：左栏列出图表缩略图、编号与译文题注，支持筛选、跳转和放大。
- **双语目录**：在原题名下显示对应章节译文；无原生目录时采用识别出的章节。与术语悬停一样，可在设置中关闭。
- **术语闪卡**：单选或批量加入指定卡组，附原句和页码。同篇同术语去重，不覆盖已编辑的卡片。

导读是 AI 提示而非论文事实的校验结果。无效或缺少输入证据的页码标灰；其他页码也应核对。术语悬停不执行正则规则，少数断词或特殊字形可能无法匹配。图表、目录与首次出现定位取决于已有块识别结果。

基于 RetainPDF（MIT），保留原有版权与第三方许可。本版不增加依赖或模型。

## 0.9.14 重新打包：内部标记与提示修复（X9b）

**0.9.13 受影响，早期 0.9.14 安装包也受影响。** 部分模型会把内部粗体标记补到章节标题中，或改变标记写法，导致它们出现在译文、PDF 目录和阅读器目录。

- 段首小标题改用独立的结构化字段翻译，题名和章节不再使用粗体占位符。数学、上下标占位符兼容大小写、下划线和空白变体。
- 升级后读取旧译文缓存时会在本地清理标记，保留成对标记内的粗体；无法还原的片段会列入质检。已有缓存不需要重新翻译，不产生新 token 费用。
- 受影响的原版式 PDF 按页修复，随后生成重排 PDF；处理中会显示本地排版进度。
- 质检和排版信息合并到「译文」侧栏顶部，默认折叠。只有需要核对的问题突出显示；用量和图内标签保留等统计放在详情。关闭摘要后，同篇文献不再自动展开提示。

如果已经安装早期 0.9.14，可重新安装本页所列新校验值的安装包：

```bash
sudo apt install --reinstall ./readflow_0.9.14_amd64.deb
```
