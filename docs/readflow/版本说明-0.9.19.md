# ReadFlow 0.9.19

本版改进原生阅读器的纯阅读体验：更清晰的页面、更稳定的拖选，以及与原文位置对应的页边批注和译文。

- **清晰度**：普通屏幕采用 1.75 倍采样；高分屏按实际设备像素密度绘制。单页最多 1600 万像素，超出时降低采样。缩放过程中保留原位图，新的高清页面完成后一次替换；屏外页释放位图。
- **选字**：文本层补齐选区尾部元素和选择状态，拖选时延后工具条与批注几何计算，避开块层、批注层和原位层的指针干扰。拖选结束后再显示选中工具条。
- **页边批注**：默认开启，卡片按原文位置排列，重叠时错开并用细线连接。评论可直接编辑，失焦或 Ctrl+Enter 保存，仍与批注面板共用原有记录。
- **块译文旁排**：单击段落，在页边显示保留标题层级、粗体和上下标的译文；底部提供复制、笔记、画布、闪卡、重译、原文等操作。↑/↓ 切换块，Esc 关闭。
- **全部旁排**：可在更多阅读操作中开启，让可视页的所有已翻译段落旁排。设置 → 通用也可选择页边批注、自动/统一右侧位置与全部旁排。
- **窄窗口**：批注收起为小图标；选中块译文使用原块上方或下方的浮卡。长卡片内部滚动，避免覆盖相邻卡片。空间足够时自动回到页边。

本版不新增模型、依赖或网络访问。侧栏与画布、原位阅读、翻译流程和数据存储保持兼容。全部旁排中的跨页译文按现有容量分配展示，不声称逐句对齐；极密页面的卡片会缩短可见高度，需要在卡片内部滚动。
