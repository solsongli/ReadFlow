# 思考画布（R3）

ReadFlow 独立实现的 DOM 卡片 + SVG 连线，不依赖画布库或上游阅读器。

- `domain/`：世界/屏幕坐标、指针缩放、命中/框选、空间分组、曲线路由、吸附/对齐、快照历史、增量差异、Markdown 提纲及安全渲染。
- `state/`：鉴权 API、每工作台实例的画布缓存与串行保存队列、手势。没有模块级可变状态。
- `ui/`：视口裁剪、节点、连线、侧栏管理、停靠视图和选择器。由工作台经 `index.ts` 装配。
- 阅读器通过 props 注册选区提供者、接收引用列表与定位回调，不依赖画布实现；工作台 bridge 连接两个功能。

节点和连线按增量写入，拖动结束、编辑结束后 300ms 防抖，多个待写操作合并为与已确认快照的差异。保存队列串行化；冲突策略为节点/连线级后写为准，不做字段级合并或多人实时协同。源码标识归后端控制，不能借编辑节点改变所属文献或批注。

画布独立存储，可选关联文献分组；删除分组只清除关联。图表卡复制一份画布自己的 PNG，原批注删除后可保留。`canvas_assets` 为资产归属台账：节点删除后保留图片以支持撤销，删除整张画布才回收其资产。文献库备份需包含 SQLite、annotation-images 和 canvas-images。

保留静态卡时冻结最新引文、色条、页码，清除 annotation_id 并标记 orphaned。未删除的来源批注仍提供当前引文与颜色。阅读器、笔记空间删除被引用批注时都要求选择；后端也拒绝未指定策略的删除。

撤销最多 50 组本会话快照；引用删除等外部修改到达时，清空受影响画布的撤销栈，避免恢复失效的批注链接。视角只保留于当前打开的视图；重启不恢复平移/缩放。分组依据完整矩形包含，重叠分组导出时按上/左顺序归入首个框。连线为端点边缘的 Bézier 曲线，不为第三方卡片自动绕障。

Markdown 导出为提纲与来源，不嵌入截图；本轮不做可选的 PNG 导出。便签支持现有 marked 的 Markdown 子集，原始 HTML 转义，图片仅显示替代文字，链接只允许 http/https/mailto。
