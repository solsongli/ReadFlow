# Paper Reader — R1 / R2

ReadFlow 原生 React 阅读核心。实现独立于 `@retainpdf/reader`；渲染使用 pdfjs-dist 4.8（Apache-2.0），基础控件使用已有 `ui/wb` 与 lucide。
工作台仅从 `index.ts` 装配，提供文献信息、带鉴权的 PDF 地址、阅读进度回调、翻译操作和 GB/T 引用格式化函数。没有 iframe 或消息桥。

- `domain/`：引用标记/参考文献/题注/目录启发式、导航历史、页映射、虚拟窗口与像素预算、纯数据契约。
- `state/`：pdf.js 加载与后台文字索引、每阅读器实例的双任务渲染队列、阅读记录 HTTP、悬停与键盘生命周期。
- `ui/`：连续页面/文本层/链接层、导航/信息面板、缩略图、悬停卡与选中工具条。
- `PaperReaderProps.toolbarTools`、`selectionTools`、`panels` 是后续工具和批注/画布/AI 的扩展位置，未传入时不显示无效工具。

主 canvas 只保留可见页与前后各一页，离屏取消任务并释放 canvas/文本层。缩略图单独懒加载并释放像素。HiDPI 支持设备倍率，同时限制单页 1600 万像素，避免高倍缩放超大分配。
目录优先 PDF 书签，否则用字号/编号。引用优先内部链接目标，再用编号或作者年份匹配；参考条目按文献章节提取，题名只做保守启发式，不调用模型或互联网服务。
图/表/式浮层来自原文题注附近的裁图；图题上方、表题下方、公式编号附近。复杂多栏、跨页表格、无标准题注、扫描件可能无法准确识别或裁全。

对照以同页号与页内比例同步，缺页一侧停在末页；可关闭同步。导航记录两栏位置与阅读模式。阅读进度以原文页号持久化，译文多出部分对应原文末页；书签分别记录原/译模式，因此译文附页也能收藏。
夜间对整个页面 canvas 反色并旋转色相；暂未实现图片区域遮罩。图表浮层保持原色。护眼米色通过页面底色与画面混合实现。
阅读时长每 15 秒提交可见、当前标签的活跃时段；超过两分钟无操作暂停计入，属于近似统计。书签、累计秒数保存在 library_mvp，时间增量用请求 ID 防重试重复计数。

旧阅读器仍独立保留。R2 使用全新的自有批注层与 schema；画布、AI/Agent、实时译文叠加及旧下载工具尚未迁入。

验证脚本在 `tests/paper-reader/`。`tests/fixtures/make-paper.py` 生成 12 页论文、14 页模拟译文、无目录版本与 100 页性能版本；无外部素材与模型调用。

## R2 批注边界

`domain/annotations` 负责归一化几何、跨行/跨栏矩形合并、路径简化、历史栈、语义名和安全的简单 Markdown。
`state/annotations` 负责鉴权 CRUD、串行写入、会话撤销与原文选区；`ui/annotations` 负责 SVG 覆盖层、工具条、编辑浮层及右栏。
页面层只接收当前可见页的批注，译文 pane 不注入该层。右栏首批 60 条，再按需展开；缩放沿用归一化坐标。

后端 `annotations` 为工作台唯一读取来源，区域 PNG 在文献库 `annotation-images/` 内，删除时清理。
旧 notes 批注通过 `annotation_imports` 台账幂等迁移；原行保留，台账防止删除后再次导入。旧视口坐标没有可靠页面尺寸时，不伪造几何：保留引文、说明、页码，并标示“旧批注 · 定位至本页”。
兼容旧 notes 写接口的原校验仍保留；通过它编辑旧记录后同步到新表。工作台自由笔记继续来自 notes，批注数来自新表，不能双算。

说明支持强调、行内代码、列表与换行，原始 HTML 转义；说明使用显式保存。撤销保留最近 50 组本会话操作，框选撤销时保留截图数据用于恢复。
导出的区域图片为本机文献库引用，不是独立图片附件；删除原区域批注后这些引用不再有效。整理成笔记仍遵守现有单条 100k 字符上限。
颜色名从工作台偏好经 props 提供，在设置 → 通用修改；导出同样使用这些名称。`N` 在有查询的搜索面板中仍用于搜索导航，否则选择便签；1–5 立即选色，同时保留数字加 Enter 跳页。
