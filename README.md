# ReadFlow：文献管理、双语阅读与笔记

[中文](README.md) · [English](README.en.md) · [Tiếng Việt](README.vi.md)

ReadFlow 是面向科研阅读的桌面工具，将文献库、PDF 阅读器、书桌、笔记和思考画布放在同一个工作台中。

文献、批注和笔记保存在本机。整理资料和阅读原文不需要模型账户；翻译与 AI 伴读使用你自行配置的服务。

## 主要功能

- **文献整理**：导入 PDF、Zotero / CSL JSON，用分组、标签、星标和待读清单组织资料。
- **双语阅读**：多标签阅读、原文与译文对照、阅读位置恢复、搜索、批注和图表查看。
- **翻译与 OCR**：按需使用本地 OCR、选段或全文翻译，配置自己的翻译服务。
- **笔记与思考**：编辑 Markdown 笔记，回看批注，将跨文献摘录加入思考画布。
- **自测与复习**：创建与原文关联的问答、填空或术语卡片，按到期计划复习。
- **阅读偏好**：设置字体、字号、浅色／深色外观及相关服务。

功能范围、配置方法和已知限制见[使用说明](docs/readflow/使用说明.md)。

## 下载与安装

从 [ReadFlow Releases](https://github.com/solsongli/ReadFlow/releases/latest) 下载已发布的安装包。当前最新发布提供 Linux x86_64 的 Debian / Ubuntu 安装包。

安装后打开 **ReadFlow**，导入 PDF 即可开始阅读。使用翻译或 AI 功能前，请在设置中配置相应服务。
